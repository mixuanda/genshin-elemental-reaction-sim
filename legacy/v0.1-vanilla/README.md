# 提瓦特伤害实验室（MVP）

一个无需构建、可直接打开的原神队伍 DPS 事件模拟器原型。

## 启动

直接双击 `index.html`，或在目录内运行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 已实现

- 单体敌人等级与抗性设置
- 1–600 秒持续模拟
- 循环行动自动重复
- 角色初始能量、行动耗能与确定性回能
- Buff、减抗、防御降低的持续时间窗口
- 行动快照与命中时动态结算
- ATK / HP / DEF / EM 倍率伤害
- 平均暴击、全暴击、无暴击模式
- 融化、反向融化、蒸发、反向蒸发
- 全队总伤、DPS、角色占比、技能占比
- 每秒伤害时间轴
- 逐段命中与完整公式因子
- JSON 导入、导出和直接编辑

## 当前限制

- 内置黑杜林融化预设用于验证事件引擎和 UI，不是经过官方数据库逐项校验的最终数值表。
- 元素附着、ICD、快照规则、命座和武器效果需要通过事件配置显式描述；尚未自动推演全角色机制。
- 粒子采用确定性回能数值，而非完整前后台粒子分配与随机颗数模型。
- 尚未包含敌人移动、无敌帧、护盾、韧性、索敌、命中范围和多目标。

## 下一阶段建议

1. 接入独立的角色/武器/圣遗物版本化数据库。
2. 增加动作帧、ICD、元素附着与粒子分配引擎。
3. 增加可视化轮转编辑器与角色表单编辑器。
4. 增加 Monte Carlo 暴击、粒子和命中随机性。
5. 将核心引擎迁移到 Web Worker，支持上万次随机模拟。
6. 增加结果分享链接和预设版本哈希。
