# 月曜圣遗物共用公式与实际事件

2026-09-24。新增如雷、乐园遗落之花、晨星与月的晓歌四件套的**月曜反应加成条款**，保持固定来源 provisional。其余条款、两件套面板、全角色机制及完整特殊反应检查点没有因此完成。

## 产品入口与记账

独立计算器的月曜贡献者编辑区可选择套装及相关条件，不要求队伍或轮转。乐园有效层数、晓歌前后台／回场残留／初始化月兆均可保持未知；只有本伤害确实需要的条件缺失才阻塞。手动反应加成明确表示不含这些来源条款的其他奖励，最终面板已包含普通属性和二件套效果。

三个可编辑合成教学示例使用同一文档与核心：`special-artifact-thundering-fury-4pc`、`special-artifact-flower-of-paradise-lost-4pc`、`special-artifact-aubade-4pc`。来源系数与合成角色面板分开标识，不冒充真实完整游戏实例。实际状态捕获保持只读，也可创建条件化编辑副本。

团队结果页可逐角色声明套装，五种月曜配置均接入：月感电、月结晶、月露涤荡、mixed v1／v2。选择晓歌须明确初始化月兆和合法换人时间轴；运行时读取真实完成切人，不从角色名称、旧轮转的隐式切人或命令起始猜测。普通伤害、普通装备条款仍由已有配置负责。

## 共享执行

`contributor.artifactBonus` 随每次贡献取样保存。来源生成类型化 AST，计算器轨迹执行这棵 AST，并展示变量定义、代入、中间结果、条件和来源；奖励先加入该贡献者反应加成，再暴击和排序。来源可信链绑定套装规则及固定来源，改变套装不能沿用另一条规则的凭据。编辑合法条件不等于改变来源系数。

- 如雷：装备者直接／反应月感电加成0.20；没有把战技减冷却条款隐含为已实现。
- 乐园：直接月绽放奖励为 `0.10 × (1 + 0.25 × 有效层数)`。实际绽放、月绽放、超绽放、烈绽放触发同一叠层状态；只有触发者获得层数。共享冷却的+60帧仍有效，整组刷新600帧。反应加成读取在到期帧清理，触发状态查询采用来源的另一种到期语义；普通快照不代替反应加成读取。
- 晓歌：合法窗口中奖励为 `0.20 + 0.40 × 满辉指示值`。初始化时固定月兆，初始前台没有残留；后台或实际换入后180帧（含边界）生效。真实换人完成与特殊任务同帧时先完成换人，再取样。月结晶在途弹保留自己的先前快照。

各条固定来源和30文件原文归档见[来源审计](cross-validation/lunar-artifact-bonus-source-audit.md)。该证据不是实机核验，也没有重新观察当前正式版本或取得真实preview。
