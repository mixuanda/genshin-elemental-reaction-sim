# 久岐忍草轮运行时来源契约

本入口把真实 E 定义接入通用周期实体、生命与伤害引擎，标注 `source-backed-provisional`，不是完整久岐忍或当前游戏实测认证。独立单击／完整技能计算器永久保留，本契约不会替代该入口。

## 明确输入

固定 gcsim `b4ae769d7c1c1bce68fce5faf0b460c5b5b7f541`：久岐忍 Lv90/90、突破6、C0 或 C2、N/E/Q 有效天赋1、钝剑 Lv1/20 R1，无圣遗物；额外 200 EM 与 -5% CR 是明确的合成参考输入。安柏 Lv1/20、C0/T1、猎弓 Lv1/20 R1，无额外属性，仅用于合法切换和接治疗。敌人 Lv90、抗性10%，无其他初始附着，两角色位于 (0,0)，静止敌人位于 (0,2)、碰撞半径2，完整处于草轮半径4内。无卡肉、无动态属性或外部伤害。

角色、曲线与武器原始数表合成后：久岐忍 ATK `212.397192 + 23.245 = 235.642192`，基础HP `12288.654441100001`，突破HP24%，最大HP `15237.931506964002`；DEF `750.7736775`、EM200、CR0、CD50%、ER100%。安柏最大HP `793.2582`、ATK `41.9434`、DEF `50.358`、CR5%、CD50%、ER100%。数值来源与唯一外部运行的原始角色快照见 `kuki-source-parameters.json/.md` 和 `kuki-e-swaps.*`。

两人初始 HP50%、能量0；初始HP是可编辑且明确的运行状态，不从伤害面板推断。C0示例在第1帧E、第51帧开始切安柏（52帧实际切换）、第300帧开始切回久岐忍（301帧实际切换），总长16秒。C2示例仅使用来源明确的延长草轮分支，未额外执行第二份外部 gcsim 样本。

## 实际生命周期与共享计算

E接受输入时耗当前HP的30%，最多降至最大HP的20%；既已低于20%不抬升血量。初击在+11帧。+23帧建立草轮，C0持续720帧，C2持续900帧；第一次tick在生成后90帧，此后每90帧一次。末端tick先执行治疗并安排+2帧伤害，再停止后续任务，所以共有8／10次环击。新草轮的来源身份替换旧身份；不预先排出整段固定治疗表，也不把死亡和刷新后的旧任务冒充新实例。

每次tick基于拥有者实际最大HP和EM，通过共享可执行公式计算治疗：

`治疗基础 = 0.03 × 久岐忍最大HP + 288.8908 + 0.75 × 久岐忍EM`

`原始治疗 = 治疗基础 × (1 + 基础治疗加成 + A1 + 受治疗加成)`

本面板基础治疗 `896.0287452089201`；在tick当下久岐忍自身HP≤50%时 A1=15%，为 `1030.4330569902581`。受治疗目标是当时前台角色；目标的HP不决定久岐忍A1状态。实际治疗按目标缺血截断，溢出量、自损与敌方受伤分别记录。治疗使用统一生命状态，因此前次治疗会影响后续A1判定。

初击普通伤害基数 `0.75712 × ATK + 0.25 × EM`，环伤基数 `0.2524 × ATK + 0.25 × EM`；通过已有普通伤害核心执行暴击、防御、抗性、附着和结构化轨迹。T1/A6固定面板保证源FlatDmg构造时与+2帧攻击快照之间的EM/ATK不变；上游“Check for snapshots”仍未以此消除。低突破初击的A4门来源冲突依然保留，不因本场景明确A6就声称解决。

## 产球、取消与冷却

只有实际草轮伤害确认调用来源粒子回调；初击没有该回调。回调先设置12帧ICD，再用严格 `< 0.45` 判定生成一枚雷微粒；owner为久岐忍，明确飞行100帧，接球前台与后场分配由实际时间线计算。随机流保留抽样和入账证据，同一配置可重放；不宣称它与gcsim共享seed的随机调用序列相同，也不把平均0.45枚直接当作每次实际生成量。

来源E动作动画长度52帧；后续普通50、E/Q52、冲刺12、跳跃11、换人50。此契约只开放E、等待、两人切换；源支持但尚未提供完整定义的普攻、Q、冲刺/跳跃不被伪造成无效果动作。E冷却ready为输入后 `7+900=907` 帧。换人延迟1帧，成功切换后全队60帧冷却；契约按合法时间线编译出的实际输入帧检查，不能通过等待或自动对齐绕过源换人冷却。

## 验证与边界

唯一外部调用的输入、二进制哈希、退出码、原始结果与样本均保留。CLI的汇总迭代与调试sample使用不同种子，分别识别，不混用随机产球能量作为同轨迹黄金结果。确定性比较以sample的实际动作、伤害、耗血、治疗时间与数值为准；本地验证还需逐击捕获并经独立计算器恢复同一伤害。

本增量不认证其他配装、动态最大HP、动态ATK/EM、移动目标、C4额外攻击或C6触发时钟；它们不能保留这个固定契约身份后静默改变意义。C2只扩展已读来源的E时长，不扩张到全命座整角色。治疗和耗血是实际执行；超出场景的自伤反应、敌人攻击、能量轮转、Q、普攻和队友技能继续保持各自覆盖状态。
