# 真实角色条件命中覆盖与缺口

状态：持续扩展。数量是可复现的命中表达式覆盖，不是角色全机制、全版本或团队模拟完成率。已发布 catalog 状态与数值/机制证据等级分别保存。

## 已落地接口

`resolveClassifiedCharacterHits(characterId, effectiveTalentLevel)` 对每个命中独立核验固定来源的完整 15 级倍率向量，返回命中及具体阻塞字段；无关队伍或其他技能缺口不会阻断已核验命中。`getCharacterDocuments(id, level=10)` 将同一输入动作的实际伤害实例交给共用计算核心，不从本地化倍率说明猜分类。每段保留来源、attackTag、HP/DEF/ATK/EM 项及 gameContext 身份。

`gameContext.abilityId` 使用 `talent:<slug>:combat1/2/3`；skillId 是稳定动作分支 ID。凯亚 E 为 `kaeya-skill`，N1 为 `kaeya-normal-1`。普攻第 N 下代表该次输入，不自动累加 N1 至 N 的前缀。香菱 N4 四段、重云 C0 Q 三柄灵刃均保留独立 hitId。

`scopeCoverage=complete-cast` 只说明所列条件下本次输入自身伤害已齐全；`selected-components` 的奥兹单次、持续技能初击或后续 tick 不得冒充完整生命周期总伤。默认最终面板是可编辑教学输入，不是假造的角色装备面板。结果始终为 `provisional-conditioned`。

## 本轮冻结的旅行者与命座依赖

最新 a7dc4bf 固定来源与活动 7.1 目录共同支持冰旅行者 E 初击、无星辉/零霜光 Q 三次自身伤害、双方 N1 及荧完整重击；荧火元素重击的第二段也已逐项重新核对。对应三个旧 blocker 保留在 `historicalTravelerActionBlockers`，从活动阻塞表退役，不能继续声称冰旅行者没有 E/Q 资料。冰形态的后续资源、领域与条件追击仍按上表具体字段阻塞。旧来源记录继续携带旧 commit，新的来源记录携带 a7dc4bf，没有静默改写证据。

草旅行者双方 E 与火转化爆炸共四条映射接入共同核心的 A4 AST：战技 `EM × 0.0015`、爆发 `EM × 0.001` 进入伤害加成区。规则读取该命中的实际最终 EM，并检查突破 4 与元素/伤害标签；手动增伤仅包含其他来源。原先要求用户手动重复计入该 A4 的假设已移除。集成测试只核对四映射接线，核心已有数值、突破与 JSON 往返回归，未重复同一算术测试。

`applyCharacterConstellationScope(document)` 在导入或换动作时读取真实命座，逐命中重建独立依赖，不将整个非 C0 角色拦截。已审阅凯亚 E 与所选 Q 单 tick 的 C0–6：C1 条件暴击只影响普通/重击，C2/C6 影响持续时间和冰棱数量而不改变该单 tick 系数，天赋命座升级由显式有效等级处理。凯亚 C1+ 普通/重击缺少冰附着/冻结目标条件时单独阻塞。克洛琳德 Q 只开放已审阅的 C0/C1；C2+ 的 A1 改系数/上限以及后续命座条件不冒用 C0。其他尚未审阅的高命座命中保留各自缺失依赖。两次调用会清理旧范围依赖，因此降低命座或更换动作不会沿用旧阻塞。

此冻结批未另跑六文件汇总；根任务统一执行最终全量单元测试与构建，最终执行结果以其验证日志为准。此前 7/8 的目录断言失败属于历史基线增量记录，不代表最终验证状态。
