# 流浪者／珐露珊：实际 120 秒捕获的独立数值核验

本次已捕获分支通过分层独立核验。原始记录 342 次流浪者／珐露珊主天赋命中（半开窗口内 341 次）、128 条 C6 父子攻击链、3 次五段 Q、83 次珐露珊 A4 均符合下述检查；主命中手算最大误差为 0。此结论针对该轴、该预设、单个种子，不是完整游戏机制认证或玩家实装／最优配装结论。

证据分为三层，不能用约 15 万次检查的数量替代机制覆盖：

- **条件算术**：342 击的最终乘法重算使用 native 的真实快照、暴击随机数及附加平伤输入；大量检查只是向量相加、字段一致、组件汇入与归属守恒。它们不能证明所有上游输入正确。
- **独立来源值／关系**：原始源表倍率和天赋索引、基础 ATK catalog；流浪者 C6 的父击倍率乘 0.4 及捕获的父子／新快照／8 帧关系；Q 段数与固定实现时机、C2 捕获点数到增伤的映射；珐露珊 Q 的 0.3825、C6 的 0.4、A4 的基础攻击力乘 0.32、实际减抗步骤的 −0.3，以及已出现状态门限。它们是对来源值和实际关系的补证，未向产品补上缺失公式节点。
- **未闭合上游**：妮可／杜林增益公式和触发覆盖由另一审计负责；本脚本未独立重建流浪者点数轨迹、珐露珊 Q/A1 的完整施加刷新／漏触发条件、图莱精确层数历史／60 帧自然加层／攻速状态时序。图莱只验证本次普通攻击返回值为 `0.096×整数层数`、范围 0–10 和已观察的 18 帧门限；攻速仅参与向量加法。本报告不消除产品 `explanationGaps` 中仍未连接的非零增益创建公式。

实际输入由 `numerical_gap_audit` 执行，未在本分支重建 native、运行全量测试或修改生产代码。固定根代码 `26864a8`，Classic 来源提交 [`b4ae769d7c1c1bce68fce5faf0b460c5b5b7f541`](https://github.com/genshinsim/gcsim/tree/b4ae769d7c1c1bce68fce5faf0b460c5b5b7f541)。独立脚本不导入项目计算器、共享公式或结果适配器，只读取捕获 JSON 与固定原始 Go 数据表。

珐露珊关键支援：

- Q 有效 13 级源表值为 `0.3825`，只加风伤槽；C6 只向风伤攻击的暴伤槽加 `0.4`。本次实际应用的向量与来源创建值均逐项核对。
- 捕获目标风抗为 `0.1−0.35−0.3=−0.55`；其中珐露珊贡献恰为 `−0.3`，另一项来自杜林实际抗性来源，未误算为珐露珊。负抗性对应 `1−(−0.55)/2=1.275`。
- A4 每次 `0.32×650.8305551=208.265777632`，基础攻击力来自固定原始 catalog，并与来源 statRead 核对。83 次实际附加均符合，未拿总攻击力乘 32%。
- 逐个状态实例核对 A4 48f、C6 崩塌 180f、风球 330f、图莱命中加层 18f 的初始门限及不早于实际过期帧再次触发。41 次崩塌包括手动蓄力箭和 C6；不可都当作 C6。能量具体增量、Q 可用性和技能冷却由 `numerical_gap_audit` 单独负责。
