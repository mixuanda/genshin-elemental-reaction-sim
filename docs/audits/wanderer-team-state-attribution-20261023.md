## 具体缺口与修复

原曲线把妮可的 **42 次投影、3,889,185.3554421375 伤害（13.1624%）**放进 `unknown`。原因是 `source-damage-curve.ts` 只按普通攻击标签分类，而两种投影都是 `AttackTagNone`。这是实际技能来源分类缺口，**没有证明原伤害金额错误**，也不是仅仅缺少公式解释链接。

固定 Classic 原件明确区分两条生成链：

| 原始攻击 | 生成键 | 原生标签 | 新曲线来源 | 实际次数 / 原始伤害和 |
|---|---|---|---|---:|
| `Arcane Projection` | `nicole-burst-hook` | `AttackTagNone` | 协同投影（妮可Q） | 23 / 1081874.8385691468 |
| `Arcane Projection: Unity` | `nicole-c1` | `AttackTagNone` | 命座投影（妮可C1） | 19 / 2807310.516872991 |

Q 投影采用对应 Q 天赋表，本场景有效 Q10 为 1.8；C1 为 6。两条链都令 `ActorIndex = 真实触发角色.Index()`，30 帧后取该角色快照、结算伤害。妮可是效果提供者，不能把投影全部转记到妮可名下，也不能把 `AttackTagNone` 改成 Q 标签来获得 Q 专属增益。

新增 `wanderer-team-state-attribution.ts` 要求固定来源 pin、准确攻击名、对应生成键、原始 None 标签、原始 ActorIndex/元素一致、实际父击与 30 帧延迟、命中时新快照。request 必须与实际 application 的 origin、attackId、calculationId 和帧一致，父链只从实际已应用命中建立。缺原始链路、伪造父 ID、别名、未知版本或字段冲突仍不分类。不依据站场角色推断拥有者。分类只覆盖已审阅 Classic pin 和本队四个角色键，不泛化为所有妮可队伍或其他来源版本。

`CurveHit.actor`、金额、事件 ID、原始帧及事件顺序不变，另附 `provider = nicole`、明确的 `mechanism`、`parentAttackId`。现有来源筛选和逐击明细自动显示上述中文标签，不需要改公共 UI。

## 新增独立状态规则：杜林 A4 消费

此前增益审计明确未重建 A4 全层数。本批从六次实际接受的白 Q、原始固定任务公式 `ceil(155.2 + 58.8*i)`、新 Q 失效旧来源和 7200f 截止生成预期消费者，不用 native 倍率当生成器。

104 次实际白龙 DoT 全部匹配。各 Q 的消费者数为 `20 / 18 / 20 / 20 / 18 / 8`；每次 Q 在来源定义的 97f 任务重置十层，各自前十次消费后归零。实际 **58 次强化、46 次未强化**，普通倍率来自原表 Q10 `1.70352`，强化取 `1 + min(当时总攻击/100*0.03,0.75)`。

本捕获的强化分支全部达到 0.75 上限；它证明本轴十层重置、消耗、旧任务取消和截断一致，不能证明未出现的低攻击未饱和分支。总攻击采用捕获的实际快照作为条件输入；其上游增益生成已有前批旁证，本批没有重复宣称独立重建所有 ATK，也没有独立重演 Aura/ICD、空间碰撞或完整队列。
