# 敌人与目标编辑器

`apps/web/src/target-controls.ts` 导出 `renderTargetControls(root, { getConfig, setConfig })`，可挂在队伍页面。编辑操作先留在草稿，保存时用现有 `parseSimConfig` 校验，只替换当前配置的 `enemy`。未编辑的可选字段不会被填写默认值，角色、行动、targeting 与其他配置保持原样。

支持共享及逐目标等级、八元素抗性、有符号防御调整、冻结抗性、初始附着覆盖、位置和命中半径；支持最多 32 个已有 schema 所允许的自定义目标。空白覆盖值继承共享参数。目标初始附着可继承情景，也可明确设置为空；仍遵守现有 aura 引擎对雷、草附着的版本限制。没有启用 aura 引擎时不会自动切换引擎。

阶段编辑使用现有半开帧区间，分别设置伤害免疫、附着阻止和命中触发阻止。移动入口使用现有线性运动模型；运动目标须具备初始位置。同目标区间的顺序、重叠、窗口边界均交给现有配置 schema 校验，不引入另一套判定规则。

添加目标不会自动扩大攻击范围或改写命中目标。`enemy-0` 保留为兼容默认目标；删除其他目标前检查配置内的 `targetId` 引用，逐条显示引用位置，要求用户先调整对应命中、阶段或运动。移除位置如影响几何命中或运动也会由保存校验明确拒绝。

此处没有敌人资料库预设，也不把自定义数值标为已核实数据。敌方元素护盾、破盾量、生命与死亡阶段未实现；伤害免疫控件不代表这些机制。
