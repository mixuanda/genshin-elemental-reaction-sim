# 圣遗物件数规则增量

本次在活动 7.1 目录的真实装备路径新增三项两件套规则。来源审计和逐文件 SHA-256 见 [件数来源审计](artifact-piece-source-audit.md) 与 `packages/game-data/sources/artifact-piece-effects/manifest.json`；43 个原始文件共 154,354 字节，附三份仓库 MIT 许可证。仍为社区固定来源交叉核对后的 `provisional`，不是独立游戏内验证。

| 套装 | 实际执行 | 来源和范围 |
| --- | --- | --- |
| 血红之证 | 合法件数 ≥2，攻击力百分比 +0.18，主副词条之后只叠加一次 | 7.1 目录及 GO `180a0a1` 的 ScarletProof sheet |
| 炉火融炼之心 | 合法件数 ≥2，攻击力百分比 +0.18，只叠加一次 | 同上，HeartOfTheFurnace sheet |
| 黑曜秘典 | 合法件数 ≥2，显式 `nightsoulFrontlineActive` ×0.15 普通伤害加成 | 目录及 gcsim `b4ae769`；该布尔值表示装备者当前同时处于夜魂加持且在前台 |

黑曜的 0/1 条件与 0.15 来源值作为 typed AST 输入提交共享核心。核心生成公式、变量说明、数值代入与中间结果；装备控件没有预先计算一个平值。其加成不限制普通、重击、战技等攻击标签，也不转换为剧变反应加成。未知条件阻止启用配装；明确 false 执行 0×0.15；明确 true 执行 1×0.15。JSON 保留同一条件与公式。此开关不是夜魂状态/事件模拟，也不代表已经核验角色技能的全部快照时点。

控件函数改为接受实际 `pieceCounts`。黑曜两件即显示一个组合条件，其他已实现四件套仍须四件才显示对应条件。黑曜四件套的消耗夜魂事件、6 秒暴击窗口及 1 秒触发间隔没有在本增量实现；血红、炉火四件套的星反应专用条款也继续保留阻塞。

新增 `artifactNonDamagePieceDescriptions` 精确登记九条不进入输出伤害的条款：四个祈冠的一件套自身对应元素附着时长减少 0.4；奇迹自身七元素抗性 +0.2；平雷自身雷抗 +0.4；渡火自身火抗 +0.4；游医受治疗加成 +0.2；逆飞自身护盾强效 +0.35。真实装备校验仍只允许祈冠冠位及来源稀有度。说明明确记录数值、对象和来源，并标记 `not-modeled`：这些条款没有被错误加入敌人减抗、治疗者加成或输出伤害，也没有计入执行覆盖。烬城二件套的 6 点能量保留为夜魂迸发事件尚未接入的阻塞，未作为充能属性处理。

覆盖函数的两件套执行条款从 50 增至 **53/59**；四件套维持 **17**；包含公式的套装从 15 增至 16。四个一件套只有准确描述与合法配装校验，没有附着计时执行。武器仍为 47 项部分或完整条款。覆盖生成文件由主任务统一刷新，本增量未重写全局覆盖文件。
