# 四类确定性武器追击：实际周期检查点

本记录覆盖笛剑、以理服人、流月针、竭泽的真实运行状态与在途追击。角色动作是明确声明的合成夹具，不是完整角色轮转的外部认证。

## 实现范围

检查点读取运行时直接导出的 `lifecycleStates`，保留有效谐音／次数、效果持续时间、触发间隔和激活间隔。到期帧等号保留为剩余 0 帧；笛剑持续状态已失效时，下一次有效命中必定重置旧谐音，才归一为 0；竭泽效果失效后，伤害门槛拒绝消耗，下一次成功激活必定重置次数，才归一为 0。不会反过来修改运行日志中的原始历史状态。

待执行回调保留真实父命中、目标、攻击标签、伤害和 FIFO 顺序；尚未取得的后续快照不会由账本推算。已排定追击保留实际快照、几何、系数及触发前后历史状态，用相对时间表示期限。

### 实测结果

- `steady-state-established`、周期 1、`checkpointCoverage.complete: true`，首末捕获边界状态相等；普通水火逆蒸发与 `target-phase-v2` 同时存在。
- 32 秒测量窗口总伤害 **1880**，DPS **58.75**，与下述独立手算一致。
- 第 1920 帧竭泽伤害 **480**，实际 `flatAtk: 200`；边界数值增益已失效，在途追击仍保留历史快照，以及触发前计数 0、触发后计数 1。
- 边界状态实际剩余期限：以理服人效果 863 帧、间隔 144 帧；流月针效果 267 帧；竭泽效果 870 帧、激活间隔 690 帧、伤害间隔 119 帧、已用次数 1。笛剑本周期已消费五个谐音，效果与间隔均已失效。
- 单独从真实运行状态取得的一谐音与二谐音检查点保持不同；第 1831 帧的二谐音期限为 0，仍保留；1832 帧后才与从未积累的状态等价。
- 同一竭泽命中的完整 `sourceResult` 经 JSON 往返后，独立计算器重现差值 **0**，`canonical-v1` 标记保留。当前 options 解析不会为历史缺失标记的输入补标记；冻结旧 options schema 拒绝该新标记。这两条窄兼容断言包含在同一用例内。

## 唯一新增检查

`packages/sim-core/src/__tests__/stateful-weapon-proc-checkpoint.test.ts` 使用一个 32 秒、四角色、合法且闭合的输入周期；预热采用明确的 `configured` 初始能量（四人均为 60），最多 8 周期、最多 1 周期重复模式：

- 笛剑在第 2、33、64、1850、1881 帧获得谐音；相邻有效谐音间隔超过 30 帧，最后两次仍在 1800 帧期限内。
- 以理服人在第 1883 帧实际施放技能，再于 1884 帧普通攻击。
- 流月针在第 1887 帧实际接收粒子，再于 1888 帧以非零普通攻击命中；全队已满能量，因此不依赖实际增加能量。
- 竭泽在第 1890 帧实际施放技能，1919 帧命中并保存包含额外 200 点攻击力的快照，1920 帧执行追击。该增益在检查点时已经数值失效，在途追击仍须保存其历史快照。

同一夹具启用既有普通 `aura-v9` 和 `target-phase-v2`：笛剑宿主施加水，以理服人宿主施加火并产生逆蒸发。宿主倍率明确为 0，所以这一普通反应验证状态并行捕获，不改变下述物理追击期望值。

在 90 级攻击者对 90 级、零物抗的单目标、零暴击率下，手工期望为：笛剑 500 + 以理服人 300 + 流月针宿主 500 与追击 100 + 竭泽 480 = 每周期 1880，DPS 58.75。此数值在测试前独立写出，上方执行记录单独提供实测结果与曾发现的差值。

同一项检查还比较未完成的笛剑谐音状态，以及第 1831 帧仍有效、1832 帧失效的持续时间边界。过期谐音只在下一次合格回调前必然被清零的情况下，才允许与从未积累的状态合并。

## 边界

这些武器采用固定来源且明确假设没有角色卡肉。旧三把确定性追击的既有支持保留；另五把随机追击和随机暴击不因此取得完整周期证明。不会把武器冷却期或效果持续期当作在途任务延长观察尾段：普通追击仅增加实际的 1 帧交付延迟。
