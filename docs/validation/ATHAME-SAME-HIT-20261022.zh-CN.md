# 黑蚀：触发 Q 命中的自身攻击增益

范围是固定 Classic b4／Stellar a7 的源模型修复，保持来源暂定。依据：固定 `internal/weapons/sword/athameartis/zz_athameartis.dm.go` 的20%／40%自身攻击、魔导×1.75及3秒条款，以及同目录实现明确指出「攻击增益应影响触发命中」的 TODO。此处没有把该 TODO 当作实机测量或全机制精度保证。

根因：角色先生成快照，`OnEnemyHit` 后添加自身 StatMod，随后伤害消费旧快照。首 Q 因而缺20%（双魔导35%）攻击。不能重新取整张面板，也不能永久另加同一增益。

补丁135使原生快照只保留明确 opt-in 的、该次原始 Amount 实际返回的贡献；Amount 不额外调用，拒绝／过期不记录，复制数值不共享可变切片。原事件仍负责碰撞后的触发资格、刷新与队友传播；Q 的 AttackMod 只补「应有自身贡献 − 本快照已有贡献」。这个 gameplay 状态不依赖 SourceHost／日志开关，并进入待执行攻击的阶段状态观察。其他属性与快照时刻不变，不为所有角色重新取样。

实证保留于云端 `mechanism-closure-20261022/athame/`：

- 旧 ad7 WASM 的有效最小输入：三项首击断言失败，E不触发的负例通过；原始失败日志／JSON保留。早期两个测试配置错误（漏队友武器、把不足四人队的共鸣当默认）另存，不计修复证据。
- 新 Classic 定向4/4：R1双魔导同帧双目标、R1单魔导、R5、E不触发。所有后续 Q 不重复添加。
- 原生无 SourceHost 的真实属性循环测试通过：只调用一次 Amount、复制贡献、拒绝值不入快照、精确过期帧剔除。
- 指定队伍只运行前6秒来隔离修复：341f首 Q `19358.177676861684 → 21142.88081857607`，差 `1784.703141714388`，与此前独立反事实精确一致；此前5笔命中完全相同。没有将该差值当作全场或实机误差上界。
