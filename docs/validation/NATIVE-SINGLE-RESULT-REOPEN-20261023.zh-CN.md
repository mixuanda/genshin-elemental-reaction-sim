**保存保真与失败行为。**

| 行为 | 本轮实现与实际检查 |
| --- | --- |
| 只读重开／再导出 | 保留原文本，包括空白、包装注释、未知扩展字段、原来源／解释缺口及全部原生记录。再导出逐字节相等，不重建历史解释身份。 |
| 编辑输入 | 明确把屏幕结果标为旧输入；结果导出仍是原档，不把编辑参数塞进旧结果。只有点击“运行一次动作”且成功收到新结果，才切换为新输入／新结果导出。 |

读取时重新**编译**保存输入只是为了比对预期脚本，并不执行脚本。检查包括固定来源、完整脚本、种子、执行模式、顶层能量覆盖、观察窗口／实际终点、目标声明／几何／主要属性、目标阶段、共享公式与能量／治疗回执、应用ID唯一及命中身份／帧／暴击标记。最多允许一次已接受角色动作；没有接受动作时不能夹带旧伤害应用。

当前单动作编译器把零能量／自定义能量写入脚本 `start_energy`，顶层 `initialEnergy` 往往缺省。本修复比较真实编译出的请求与完整脚本，**不会为了检查或显示补一个假能量回执**。`createSourceHostResult` 用于共享公式／回执一致性检查，但保留文件原结果，而非采用它新生成的解释缺口列表。
