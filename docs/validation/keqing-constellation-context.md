# 刻晴 Q C4/C6：逐击条件与面板记账

本轮在既有十击完整 Q 和独立单击入口上，补齐 C4/C6 的明确条件计算。没有新增角色伤害实例；映射版本更新为 `reviewed-hits.14`，所选 Q 的命座范围扩为 C0–C6，数值与机制仍为暂定。对未知状态按实际选中命中阻塞，不把其余九击的缺口变成独立单击的前置要求。

## 实际实现

- [模型](../../packages/sim-core/src/calculator-model.ts) 增加 `keqingBurst.hitStates[hitId]`。每击分别保存 C4 当前有效、共享 ATK 已含份额、可选明确基础攻击、C6 普攻/重击/初次 E 三个类别是否有效，以及本击已填增伤中的 C6 类别数。旧 JSON 缺少此记录时解析为空；未知字段没有默认为无效。
- [来源公式](../../packages/sim-core/src/keqing-xingqiu-formulas.ts) 和 [适配器](../../apps/web/src/keqing-xingqiu-calculation-context.ts) 使用现有共享 AST 与攻击调整步骤。C4 差值为 `基础攻击 × 0.25 × (当前有效 − 输入面板已含)`，直接加入本击 ATK，不再次乘 ATK%。来源装备基础攻击等于角色基础加武器基础；手动/导入只有在需要补加或移除时要求基础攻击，绝不从最终 ATK 反推。两份状态相等时修正为零，无须补造基础攻击。
- C6 使用 `0.06 × (1 + 普攻类 + 重击类 + 初次E类 − 已含类别数)`。本 Q 的 `burst` 类在起手同步刷新、持续 480 帧，而十击在 56–197 帧取样；故该类别计一次。相同 key 覆盖刷新，先前 Q 不能再添一层。其他三个类别每击单独输入，可在中途失效或建立；不从所选反应推断 C4，也不自动模拟持续时间、卡肉或前序动作。
- 原稳定声明现在明确限定为“基础面板和 C4/C6 以外的装备、目标状态”；C4/C6 自身允许逐击变化。未声明基础稳定时，多击合计被阻塞，单选一击仍可使用该击实际面板。
- [逐击控件](../../apps/web/src/calculator-keqing-controls.ts) 按十个命中分别显示三态选项及可留空数值。`resetKeqingPanelAccounting` 在新来源配装时设“未含”，在新展示柜最终面板时清除 C4/C6 记账和旧基础攻击为未知；临时状态不由展示柜证明。主任务负责 UI 事件和导入入口接线，浏览器及构建状态不由本记录代替。
- 保留逐击最终 CR 覆盖优先、独立反应、单击选择、JSON、转最终面板及来源配装重新应用。C4 来源攻击修正与 C6 增伤均展示实际公式、变量、代入和中间值。
