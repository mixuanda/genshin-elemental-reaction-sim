固定来源为 gcsim `b4ae769d7c1c1bce68fce5faf0b460c5b5b7f541`。数据代理已单独完成 [来源映射核对](../cross-validation/noelle/source-mappings.md)；此处没有重复运行其 180 项天赋向量核验。

实际实现：

- 普攻 1–4、重击旋转/终结、下落碰撞/低空/高空动作使用显式 Q 状态；Q 激活时改为岩元素，保留普通/重击/下落标签。
- Q 两段均为爆发伤害；独立有效 Q 等级同时决定其伤害系数和防御转换系数。普通/重击/下落自身天赋等级不跟随 Q 控件改变。
- 来源式为 `历史非 Extra DEF ×（Q 转换系数 + C6 0.5）`，结果作为固定攻击力追加，不乘攻击力百分比。历史 DEF 不从当前最终 DEF 自动重采。
- C2 只对重击旋转/终结加入 15% 普通伤害加成。C4 护盾爆炸不归入这些输入。
- `attackAdjustment.accounting` 明确区分尚未计入和已经包含在最终攻击面板。缺少必要历史快照时只阻止相关动作；已包含模式不执行历史转换、不要求未知的历史防御。
- 装备转为最终面板后，保留原构筑基底及每段的来源调整/记账方式；不会把不同命中状态压成同一最终 ATK。JSON 保存并恢复相同表达式、来源和输入。
- 共享追踪节点 `sourceAttackAdjustment`、`hitAttack` 直接执行 AST；天赋缩放读取同一个实际命中 ATK。装备声明读取最终面板的命中公式也读取该值；声明读取转换前属性的条款不把 Q 的 Extra ATK 二次转换。
