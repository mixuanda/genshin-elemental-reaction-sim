# 新增机制与编辑器浏览器验收

本轮只执行 `apps/web/e2e/next-increment.spec.ts` 的三个综合场景，使用固定 4173 生产预览、Chromium、单 worker。未执行旧 43 项或此前新增场景全套；测试不自行构建。

## 首轮执行

命令：`GIDPS_PREBUILT=1 npx playwright test apps/web/e2e/next-increment.spec.ts --workers=1`。

日志：`next-increment-e2e.log`。结果为 3 项失败、exit 1；失败原因分别为：

- 装备：VV 抗性 `0.1 → -0.3`、伤害按 `1.15 / 0.9` 变化、最终面板转换及 TF 的 `0.2` 超激化加成／`0.15` 雷增伤检查已过。随后测试查找了错误的轨迹 ID，已改为真实命名 `additive.additiveReactionDamage`，数值断言未放宽。
- 行动编辑：页面显示 `Cannot set properties of null (setting 'textContent')`。说明文字代码读取 textarea 的下一兄弟，但 textarea 位于 label 内，实际说明段落是 label 的下一兄弟；主代理负责修复。
- 特殊执行：SSC 与 LB 数值和首次单击复现已过。LB 第一次送到计算器后，返回结果页清空了独立运行结果，无法继续打开第二、三段；交主代理修复导航保留。

日志：`next-increment-e2e-rerun.log`。三个受影响场景全部通过，**3 passed，5.9 秒，exit 0**。

- 行动编辑说明改用稳定定位；请求帧、`for` 角色绑定、闪避／跳跃／拾取、可视上移／下移、保存后实际指令均通过。安柏来源 `at 1f N5` 展开五条并可编译；`N6` 明确拒绝，未生成不存在的行动。
