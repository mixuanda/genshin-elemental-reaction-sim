# 诺艾尔 C6：普通动作轴不再隐式赠送十秒延长

审查基线 `8b7d36227d92c4edd352c981dd2166e3aa3d2bac`；独立实现提交 `2d903ba`。父线程负责公共编译入口、就地控件、浏览器及整合。本文记录本分支实际执行，不代替父线程的浏览器验收。

## 具体问题与修复位置

普通点选轴原 `compileSourceTeamDraft()` 直接输出未填写的参数；诺艾尔 C6 Q 因而成为 `noelle burst;`。两个固定上游的 `internal/characters/noelle/burst.go` 都将省略的 `extend` 解释为 10 秒，在 Q 施放时直接加到持续时间，不等待击杀或后台事件。普通页面同时提示 E/Q 通常无需参数。对全程前台、无击杀的轴，这个未声明假设会实际延长 DEF 转攻和岩附魔，改变命中伤害及反应条件。

这是普通输入的默认策略缺陷，不能据此称固定上游的参数协议错误。上游还引用了[诺艾尔后台到期可最大延长的实验](https://library.keqingmains.com/evidence/characters/geo/noelle#noelle-c6-burst-extension)，所以“没有击杀”本身不能证明所有延长均错误。本次复现额外限定全程前台，修复也不宣称已经自动模拟这两种延长。

新增 `packages/sim-core/src/source-noelle-burst-policy.ts`：

```ts
resolveSourceNoelleBurstParameters({
  sourceRevision, characterKey, constellation, actionKind, parameters
}) // => { parameters, extension?: { seconds, origin, message } }
```

- 只对已核两个 pin 的 `noelle`、C6、`burst` 生效。普通轴没有明确延长时，返回独立参数副本并写入 `extend: 0`。
- 明确 `extend` 须为 0–10 整数；保留原值，不重复追加，不把未知、字符串或非法值钳成可算数值。未核来源拒绝推断这个参数。
- 其他角色、动作及 C0–C5 不新增 C6 条件。输入对象不写回，JSON 保存重开后的明确参数保持一致。
- 只供普通轴新编译使用；固定原生默认、高级 GCSL、旧结果、原始脚本文本及持久格式均未修改。本分支未修改公共 UI 或 mapping 版本。

父线程最小接线为：用返回的 `parameters` 替代编译处 `action.params ?? {}`，并在本步提供额外延长秒数和说明。非零代表本步明确假设；默认零不等于宣称真实战斗绝无延长。

## 短边界与唯一一次 120 秒

短探针仅 Q 两次命中后等待至所选 N1。Q 在 F1 施放，固定源基础持续 `900+80` 帧，到期 F981；两次实际命中分别产生 13 帧卡肉，得到 F1007。独立三个运行证明 F1006 仍有转攻／岩附魔，F1007 和 F1008 已是基础 ATK／物理。Classic、Stellar 各 4/4 测试通过，明确 10 秒仍保持原结果。

仅额外执行一次 Classic 120 秒：一开始满能，一次 Q 后连续 N1–N4，种子 `20261023`，正常执行至 F7200；没有周期补能、能量绕过、敌人掉球或再次施放 Q。110 击为 Q 两击及普攻 108 击；普攻中岩 16、物理 92，末击 F7137。连续普攻的实际卡肉累计延长 198 帧，使本场零额外延长的 Q 到期为 **F1179**；这不是上述短探针的 F1007。
