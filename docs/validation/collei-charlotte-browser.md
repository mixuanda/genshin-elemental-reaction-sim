## 两条流程证明的行为

1. 柯莱：未提供回收历史快照或触发/持续条件时完整技能阻塞；单选飞叶轮可独立计算，单选新叶仍要求历史快照。两次新叶明确触发后按四个真实命中合计。修改当前 ATK 只改变往返两击，两次新叶保持原值。C2 的新叶期间反应明确为是时，回收前反应保持未知也能确定四次新叶；六击总和、共享历史上下文和轨迹经 JSON 往返一致。清除快照后完整分支再次阻塞，飞叶轮单击仍可计算。
2. 夏洛蒂：A4 队友人数未知时不能当作零；明确人数 2、3 分别使用 10%、15% 冰伤。单击在后续标记持续和面板稳定未知时仍可计算；完整分支要求恢复两项确认。C2 分支明确阻塞。点按五击、长按九击均与独立系数算式和逐击合计相符；正常页面能展开 A4 AST 的实际数值代入。显式逐击已含 10% 时，九个 `customDamageBonus` 节点均补入 0；JSON 保留当前人数、记账和完整轨迹，伤害没有重复增益。
