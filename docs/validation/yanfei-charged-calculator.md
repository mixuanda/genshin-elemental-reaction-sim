# 烟绯：单次重击与条件法兽灼眼

2026-09-24，独立计算器在角色烟绯的「火漆制印·一次重击（含条件法兽灼眼）」入口执行；不要求队伍或轮转。两段使用现有普通伤害公式核心，新增的是来源条件适配和一次暴击触发归属，未实现另一套伤害引擎。

## 实际来源与范围

固定来源为 gcsim `b4ae769d7c1c1bce68fce5faf0b460c5b5b7f541` 的烟绯 `charge.go`、`asc.go`、`cons.go`、`burst.go`、`yanfei.go`、`zz_yanfei.dm.go` 及通用角色属性实现。7 个原文件已归档；manifest 记录 SHA-256、固定 URL 及逐字节比较。五组重击倍率（0–4 印）分别对应 `combat1.param4..param8`，独立灼灼增伤对应 `combat3.param2`；15 级完整向量共 90 个数与活动数据目录完全一致，最大绝对差为 0。

这证明固定源、归档与目录字段一致，不等于当前版本游戏实测。完整来源记录：[manifest](../../packages/game-data/src/character-mappings/yanfei-charged-source-manifest.json)。

## 实际计算

- 重击消耗 0–3 印；4 印要求 C6。主击的来源 AST 按实际印数选择对应有效普攻天赋倍率。
- A1 解锁后在本次重击排队前替换旧效果；适配器从每段已填增伤移除显式声明的旧 A1，再加入本次印数 × 5%。默认已含值为 0，不能借此凭空获得额外增伤。
- 灼灼使用独立有效 Q 天赋，主击和 A4 各自明确激活状态。先扣除每段手动增伤中显式声明的已含灼灼，再加入该段适用值，不自动叠加 C5 的等级。
- C2 按每段实际结算前的目标生命比例严格 `< 0.5` 判定 +20% 暴击率。主击/A4 两次目标生命输入独立，不根据主击伤害反推未知生命上限。
- A4 解锁且主击暴击、命中敌人、主击回调时仍在场时，本次输入只触发一次 80% ATK 火元素重击。A4 自己独立暴击和反应。主击/A4 的各类伤害乘区照常由共享普通公式计算。
- 整次输入：全非暴击分支 A4 贡献为 0；全暴击分支加入一次 A4 暴击伤害；期望贡献为 `P(主击暴击) × E(A4 | 已触发)`。结果对象保留实际 A4 的三种伤害，并另存 `castContribution`，两者不能混淆。
- 单击模式只选 A4 时，以追击已经触发为明确条件，显示实际单击伤害，不乘主击触发概率。若 A4 已知未解锁或主击时不在场，则显示不产生伤害实例，不虚构已触发的单击；突破未知仍属于缺失依赖。
- 主击和 A4 的快照分开发生。现有条件模式要求明确声明两次快照的共享面板和装备状态稳定；未声明时 A4 阻塞，独立主击仍可算。反应、灼灼和 C2 目标生命保持逐段独立。
- 最终面板转换与 JSON 序列化保留 occurrence 和来源公式。明确的本段最终暴击率覆写优先于角色公式；修改 C2 目标条件不会推断该覆写的组成、自动增减它。需要重新按 C2 计算时，用户须清空该最终覆写；重新应用装备按既有流程清除旧覆写。
