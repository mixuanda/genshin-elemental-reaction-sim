# 确定性角度算法与跨运行时严格重放

本轮基线：`943ec4393865e2c36317e2ccd9d582246b4f02ca`。
包含配装反馈与浏览器流程修复；本报告只记录本地验证，不表示已经发布。

## 已证明的根因及实际修复

`test-seed:dendro-core-position-v1` 第一抽为 `0.37926428369246423`，
生成角度 `2.382987774834482`。原生 `Math.sin` 在 Node 24.19.0 返回
`0.6879095408754938`，在 Chromium 154.0.8037.57 返回
`0.6879095408754939`。半径 0.5 的草核 y 坐标因此相差一个 binary64 步长，
后续距离也可能不同。完整重放的精确比较拒绝了这种差异，行为本身正确。

新模块 `packages/reaction-formulas/src/deterministic-angular.ts` 采用
[fdlibm 5.3](https://netlib.org/fdlibm/readme) 的明确系数、角度约化和运算顺序，
不调用原生 sin/cos/atan2，也不对最终结果做量化或舍入。
FDLIBM 本身是高精度近似算法，不能称为每个输入都正确舍入的数学库。
其原 Sun 许可声明保留在源码、第三方声明和 Web 产物的独立许可文件中；
来源与 SHA-256 见 [fdlibm-angular-sources.json](./fdlibm-angular-sources.json)。根许可证不变。

## 算法版本和旧记录

运行选项增加可选字段 `angularGeometrySemantics: "fdlibm-angular-v1"`。

- **缺失标记：** 保留原生 Math 路径，不补默认值，不改原结果或旧复现身份。
- **新浏览器运行：** 普通 Worker 与特殊宿主 Worker 显式加入该版本；
  延迟轴的基线和最终执行使用同一选项。
- **记录与重放：** 有效选项写入结果和 manifest，参与复现 key。
  导入分支直接使用保存的选项，不套用新运行的默认值。
- **失败关闭：** 未知/null 版本、请求标记被删除、结果/manifest 标记不一致，
  以及 1 ULP 坐标篡改均被拒绝。精确 canonical 比较未放宽。

因此无需把全局 1.53 身份改成另一身份或重写冻结 Golden。
此字段表达的是一个新的、可审计的运行算法选择，不是旧结果的自动迁移。
历史原生算法记录仍可能受原有跨运行时差异限制；不会被冒称为新算法验证成功。
旧文件只读、编辑后另存新格式的既有策略保持不变。

## 精确覆盖范围

选定算法用于草核和结晶落点、角色局部坐标变换、矩形旋转和扇形角度判断，
校验端使用同一选项。schema 允许的角度及扇形边界均在 ±3π 定义域内。
距离仍使用既有策略；Math.hypot、伤害公式、时间帧、RNG 算法和消费顺序没有更改。
本次没有宣称所有 JS 数学函数、所有平台或所有角色机制已完全可移植。

独立 384 位 BigInt Maclaurin/Machin oracle 检验 3287 个角度与 2650 对 atan2 输入；
分别在 1/2 ULP 数学近似精度界内。另一次独立 200 位 mpmath 检查覆盖
70 个边界角度和 348 对输入，未发现移植错误。
这些精度检查不是对模拟重放设置容差：Node/Chromium 重放仍要求逐位结果一致。
