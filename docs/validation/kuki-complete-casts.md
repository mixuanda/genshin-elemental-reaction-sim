# 久岐忍独立 E/Q 完整伤害增量：实证记录

## 实际修改

- 新增四个具备独立命中选择的条件动作：E 初击＋8环（C0–1）、E 初击＋10环（C2–6）、Q 施放HP>50%七击、Q 施放HP≤50%十二击。移除旧三条 partial 注册；其组成仍可在完整动作中单独选择。
- E 使用共享 AST 执行 `ATK × 天赋倍率 + EM × 25% × A4解锁`；Q沿用 HP 倍率普通伤害核心。独立数值代入、变量定义、中间结果、反应、防御、抗性、暴击与汇总轨迹不另建引擎。
- 新增 `gameContext.kukiDamage`、三态实际条件控件、施放Q生命比例、C6有效/面板已含记账及实际最终EM声明；JSON、导入和来源配装重建保留明确上下文。最终暴击覆盖优先，逐击反应独立。
- C6 来源配装使用 `150 × (有效 − 已含)` 精通差值。手动/导入实际最终EM可明确恢复；未知状态只阻塞依赖它的伤害。低突破初击的来源冲突精确阻塞，其他环击/Q可独立计算。
- 真实角色入口 Q 生命比例未知留空；不把用户选择某分支当作已提供实际比例。稳定与完整持续是可编辑教学假设，有可见文字说明。
- 注册版本 `.14 → .15`，固定 gcsim 和 Optimizer 原始来源、哈希、活动目录比较、冲突与适用边界均已归档。相关源码和来源说明见 `docs/cross-validation/kuki-complete-casts-source-audit.md` 及 `kuki-optimizer-source-audit.md`。
