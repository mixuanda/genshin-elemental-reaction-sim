# 接触与标记完整施放协议（.23）

本批增加凯亚Q、胡桃E血梅香、埃洛伊E主弹／小弹三个有条件的完整施放入口。它们复用已有 observed-entity 文档、结构化公式、最终面板与单击回放，不依赖队伍或轮转。未知接触保留阻塞；明确落空才不计入该目标伤害。

## 实际实现

- 凯亚C0：固定源码的13次旋转机会为53、93……533帧，均采用起手第0帧快照，观察至534帧。必须逐次声明目标接触并确认来源简化。本入口不声称涵盖游戏中的14／15次接触。
- 胡桃C0：E自身总伤仅包含血梅香。实际重击记录负责施加／刷新标记，重击伤害仍归普攻。彼岸蝶舞554帧状态、重击延长108帧及结束回收、+3帧接触、570帧标记、240帧旧相位检查、标记代次与真实切离共同生成血梅香事件；刷新不会重启既有跳伤相位，E结束后的无关普通重击不会刷新本E标记。
- 埃洛伊C0：显式输入源码 travel、bomb_delay、bomblets 参数；主弹快照20帧、伤害20+travel，小弹统一快照20+travel、随后每6帧一枚。数量未知不采用默认2。该条件完整分支仅认证固定来源简化日程，不认证真实散落物的碰撞、寿命或全局线圈数；其他目标接触不由当前目标记录反推。

胡桃每次伤害使用共享公式树：`[本击ATK + 有效时min(E起手MaxHP×转换率,4×E起手BaseATK) − 面板已含转换ATK] × 血梅香倍率`。转换率读取归档的15级向量（一级0.03841）；A4按明确的本击取样HP比例计算，并减去面板已含份额。E起手扣血也生成数值代入与解释，但不以起手扣血推断所有后续生命比例。

完整日程保存每次实际取样时彼岸蝶舞是否有效；单个已发生命中可独立明确此状态。只有状态有效的命中身份依赖E起手最大生命与基础攻击。末段状态无效的已发生命中不依赖未来重击列表或不适用的转换输入。换装备后转换份额的已包含记账会重置，历史起手数据保留为显式输入。

## 来源与限制

代码来源提交为 gcsim `b4ae769d7c1c1bce68fce5faf0b460c5b5b7f541`，归档与映射见 `packages/game-data/sources/observed-entity-casts/`。本批增加5组倍率向量／75个值和28份原始文件，保留 .22 历史文件与hash，不覆盖旧证据。

本协议明确限定C0、无卡肉延长、无中断／替换、完整观察及明确快照或跨命中面板稳定声明。胡桃重击若恰好在当前彼岸蝶舞到期帧且未有已记录的先行Stats取样删除状态，本记录不足以判断其他取样顺序，完整日程保持具体阻塞。凯亚旋转最大次数、埃洛伊散落物完整游戏生命周期，以及来源中的快照／被动检查间隔TODO没有被标为已验证。三协议不是自动团队模拟已完整支持的声明。
