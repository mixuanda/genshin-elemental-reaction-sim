# 信使弱点来源与结果完整性

本轮范围是信使的实际普通伤害回调和独立物理追击。依据固定 gcsim `b4ae769d7c1c1bce68fce5faf0b460c5b5b7f541` 的 `internal/weapons/bow/messenger/messenger.go` 与 `pkg/enemy/damage.go`。数值仍为明确来源条件结果，未升级为游戏实测 verified。

## 实际改动

- 当前配置命中可明确提供 `hitWeakPoint`；信使持有者全部已配置命中模板（也包括召唤／周期实体引用的模板）必须提供布尔值。未知不等于 false。弱点 true 与禁止暴击互相矛盾，配置拒绝。
- 当前伤害事件和实际普通公式输入保留该字段。独立回放从配置命中身份或已重放的信使自产追击建立弱点事实，不信任事件或被动日志的自报值。
- 信使回调按实际同帧 FIFO、前台、弱点、来源冷却顺序核验；成功后独立来源命中自身为弱点 true。固定代码没有额外重击标签或非零伤害筛选。
- 弱点命中使用 allCrit，保留真实面板暴率，且不抽取暴击随机数。执行审计校验 configured／eligible／critical、空 roll／drawIndex 和来源一致的普通公式上下文。插件不能伪造或取消该保证。
- 捕获回放直接复用共享核心的弱点条件 AST；来源武器倍率也复用独立计算器的同一倍率公式。来源父命中的暴伤覆盖不传给独立武器攻击。
- 团队模拟武器许可名单明确为原十二把加信使，共十三把。另三把新增来源定义仅供独立计算器，不因 canonical 列表扩大而自动成为可运行被动。
- 旧配置与旧十二把武器未声明的字段仍省略，旧冻结版本不接受新命中字段。
