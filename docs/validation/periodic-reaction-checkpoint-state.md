# 普通周期反应实际状态检查点

本批实现感电、燃烧、草原核与结晶的真实私有状态捕获。它扩展现有普通 Aura / target-phase-v2 检查点，不重建第二套反应日程，不修改反应公式或资料验证级别。本文记录实现和静态来源核对；未在本子任务运行测试、构建或数据脚本，实际数值与周期结论由根任务统一验收。

统一验收暴露的实际问题已定点修正：失效的感电到期 token 不再生成没有 Reactable.Tick 转换的生命周期点；当前版本的草核生成、接触、消费与实体时间线按实际来源事件相位和序号互相绑定，包含多目标燃烧的目标次序相位及后置输入子事件。历史版本保留原有叶子约束，当前版本也不接受脱离来源的任意相位。失败证据保留在 `remaining-horizontal-core.retry4.log` 与 `remaining-horizontal-core.retry5.log`；本段不表示修复后复验已通过。

## 捕获边界与接口

`AuraEngine.captureOrdinaryState(true, true)` 不推进时钟、不调用舍入后的公开快照，读取实际 Gauge、来源槽、衰减率、ICD、感电与燃烧私有状态。`DendroCoreManager.captureState()` 读取实际实体、预留 ID 集与分配游标，不生成实体或抽取随机数。

`PeriodicReactionHostState` 由主模拟器提供实际的感电/燃烧来源 Map、到期去重 Set、清理任务存储、草核来源和管理器状态、结晶碎片/护盾、身份游标以及未结束的内联交付计数。`normalizePeriodicReactionHost` 与已有检查点共享真实队列；队列的帧、priority、FIFO 顺序保留在主检查点中。

主模拟器已接入该接口。真实未来任务保留仅用于 current schema、legal-frame-v1、普通反应、禁用目标时钟以及 target-phase-v2 / legacy-event-heap-v1 的支持域；旧阶段与特殊反应注入仍保留原路径。任务来自实际反应调度调用，不从输入或日志重建；GCD 阻挡和 scheduled=false 仍不入队。执行循环仍在原 duration 截止，公共 withinSimulation=false 不被改写；检查点显式保留超窗标记。递归碎冰若出现超窗内联伤害则独立阻塞，不提前执行。

## 实际状态与归一化

- 感电保留当前代次、首击固定快照、独立周期回调、Wane 监听、休眠状态、待清理期限及对应实际可变任务行。旧代次仅在没有当前状态、队列或清理引用后剔除。提前结束但尚待清理的终止行关联仍保留；清理会读取该行，不能当作纯日志丢弃。
- 燃烧保留伤害与燃料来源、冻结面板、反应加成、燃料附着/耗尽时刻、衰减率、下一回调及附着 ICD。第九次跳伤之前保留计数原值；第九次以后同步平移实际游标与所有保留任务引用，保持相等比较。可信 Burning ICD 到期等号仍有效。
- 草原核保留真实预留、生成任务、活跃实体、位置、寿命、所有者及后续伤害上下文。ID 相对实际分配游标归一化，活跃/已失效到期 token 的相互关系保留；不会从日志虚构草核。
- 结晶保留实际碎片、可拾取时刻、几何、生成时等级/精通、真实护盾计算与剩余基础盾量。被替换实体的旧到期 token 仍在队列中。拾取属于实际静态输入计划，不能把一串尚未发生的拾取当成已经发生。
- 草核与结晶位置各保留真实具名 PRNG 的全部状态和抽样计数。完整捕获不等于确定性稳态，不以固定种子宣称与外部模拟器共享随机序列。

绝对审计行号、已经不可再读取的历史代次和单调分配基准可以规范化；影响来源、数值、先后顺序或下一次分支的内容必须保留。窗口外的未来任务必须实际存在于主队列，不能按配置补造；其观察范围标记若影响真实执行也保留。

## 保留的边界

目标时钟、target-phase-v3 内联交付、特殊反应注入、插件私有状态、实际机制截断继续独立阻塞。检查点只能证明当前已实现来源模型与完整给定输入域；草核固定来源的 300 帧寿命仍保留原 provisional 说明。已执行当前帧、尚未提交的反应附着、未被主队列接收的清理结果均不能标成帧前完整状态。

同时接入来源普攻连段的真实 `SourceNormalChainState` 与实际换人起手重置任务。计数归于 `activeCharacterAndActionPhase.sourceNormalChain`；换人命令的绝对索引剔除，真实目标、声明、起手帧和相位顺序保留。没有来源连段配置时不增加旧检查点字段。
