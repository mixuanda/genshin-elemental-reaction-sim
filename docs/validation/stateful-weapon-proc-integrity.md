# 四把状态武器：独立结果重放与来源状态校验

本轮接入笛剑、以理服人、流月针、竭泽的当前版本配置及结果状态。它们是独立物理追击，不加入宿主技能的基础伤害。固定来源为 gcsim `b4ae769d7c1c1bce68fce5faf0b460c5b5b7f541`；来源归档、来源间差异和外部对照见 [专项来源审计](../cross-validation/stateful-weapon-procs-external.md)。这些范围维持固定来源假设，不升级为当前游戏全机制 verified。

## 实际改动

- 配置枚举、显式武器类别、互斥及当前版本日志接入新四把；新四把要求合法时间轴。旧八把不增加状态字段，旧版本不接收新生命周期日志。
- 共享来源表提供伤害倍率、半径和纯状态转换；半径分别为笛剑 4、以理服人 3、流月针单体、竭泽 2.5，不继续把所有范围追击写成 3。
- `weaponProcLifecycleLog` 记录实际技能事件或粒子接收事件，每条引用真实 `actionLogIndex` 或 `particleEventId`。伤害回调保留 `stateBefore`／`stateAfter`，包括窗口、音符、次数、触发与激活冷却。
- `weapon-proc-replay.ts` 从已接受技能、实际粒子来源绑定和普通命中回放这些状态。导入日志不能自行创建窗口、补音符或恢复次数。能量不足的技能请求不产生已接受技能事件；固定回能不冒充拾球；后台领取的能量份额不代表拾球者。
- 粒子接收复用现有能量来源和连续 EnergyLog 绑定。接收阶段 2／12 来自来源排程，前台身份受完整能量重放验证；同帧动作 0／8 与回调 3／13 分段，不能只比较帧号。
- 结果校验核对实际回调顺序、状态变化、独立追击身份、范围、快照及共享伤害乘区。计算器捕获保留完整来源结果，并复用独立计算器的倍率 AST；已解析最终面板不会再次叠加武器。

## 来源边界

`OnSkill` 在来源 `useAbility` 中同步发生于技能函数之前；当前接线使用已经通过合法性与能量检查的实际施法。来源技能函数内部返回错误的情形不在当前合法动作合同内，不能泛称来源中任何失败都会撤销事件。

这四把使用 `Status`，到期帧仍有效，查询只检查期限而不删除保存的过期值。笛剑仅在通过音符门槛后检查是否清旧层；竭泽第三次追击删除效果、不写新的伤害冷却，重新激活也只删除来源判为仍有效的旧伤害冷却。没有添加通用定时清理。

该模式明确无角色卡肉，只支持既定宿主事件阶段及普通伤害回调，不声称恢复 gcsim 的任意跨队列 FIFO 或覆盖全部反应回调。独立单击计算仍以一次已经触发的追击为前提，不强制用户建立轮转，也不乘触发概率或剩余次数。

实测断言结果：

- 竭泽 R1、ATK 1000、同级敌人、无暴击／物抗：实际追击触发帧为 1／122／243／722，各为 `1000 × 0.8 × 0.5 = 400`，含七次宿主命中的总伤害为 **5100**。第 121 帧仍被冷却阻止；第 243 帧第三次追击把窗口删除，保留旧伤害冷却 242、激活冷却 720。第 60 帧能量不足的 E 没有激活日志，第 300 帧已接受 E 被激活冷却阻止，第 721 帧重新激活。
- 竭泽第三次追击经过完整结果 JSON 与命中捕获 JSON 导入后，共享计算器复现差值为 **0**。删除激活记录、把激活来源换为普攻、伪造第三次之后的窗口或次数，均被完整结果校验拒绝。
- 流月针 R1：第 1 帧另一角色在场接球，持有者虽收到后台能量份额仍不激活；第 6 帧持有者满能接球照常激活。固定回能未产生激活日志。持有者退场后的第 17／306 帧普攻各触发 `1000 × 0.2 × 0.5 = 100`，第 307 帧普攻不再触发，总伤害为 **1700**；不存在额外追击冷却。两次持有者实际粒子入账均因满能量为 **0**。
- 流月针完整结果 JSON 通过校验；伪造后台接球激活或更换真正激活所引用的粒子事件，均被拒绝。

这些定点结果证明上述共享来源合同与独立重放的一致性，不将合成夹具冒充角色动作资料或当前游戏实测。笛剑／以理服人的纯状态和运行验证由相应专项记录报告，不从本文件推导未执行的测试。

## 后续实际失败触发的窄修

同轮检查点用例发现既有平值增益写入 `atkFlat`／`hpFlat`／`defFlat`，但总属性读取 `flatAtk`／`flatHp`／`flatDef`。当前结果选项新增可选 `flatStatBuffSemantics: "canonical-v1"`，仅合法帧运行可使用；新运行由运行时显式写入。结果重放的普通面板与召唤物后备面板只在该标记下转换字段名。缺标记的历史当前版本捕获继续原语义，旧版本严格选项不接收新标记。现有完整运行身份哈希直接包含真实选项，未另建兼容或哈希框架。

实际零数量粒子在固定来源仍发出接收事件。当前配置另行校验非负固定数量与下限为零的范围，并在公共冻结校验投影后恢复原数量；旧版本固定数量、范围下限仍严格为正。结果数量字段本来已允许零，无需扩大旧结果格式。

这些后续窄修由原先失败的检查点用例与武器运行用例定点复验，本专项没有另开测试或重跑先前已通过的两例。最终实测以对应的检查点／运行日志为准。
