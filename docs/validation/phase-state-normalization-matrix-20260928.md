# Actor phase-state normalization matrix (2026-09-28)

This matrix documents only the read-only actor exporter changes in `077-phase-state-normalization.patch`. A normalized value means the inspected future gameplay readers cannot distinguish the folded states. Equality boundaries remain distinct where a reader uses `<` rather than `<=`. No callback or concrete private state is claimed to be serializable.

| Exported field | Treatment | Source-derived reason |
| --- | --- | --- |
| Character `timePassed` | Omit raw clock; retain `localClockLag`, hitlag frames, and local task deadlines. | `pkg/core/player/character/hitlag.go` advances the local clock; `pkg/core/task` schedules relative to it. Chasca `internal/characters/chasca/skill.go` stores a local action-start timestamp inside a closure and uses an elapsed difference. Skirk `internal/characters/skirk/cons.go` stores local timestamps in a private C6 stack and compares `src+c6Dur >= c.TimePassed`. Those captured timestamps remain explicit concrete-state/closure gaps; omitting the raw common clock does **not** certify Chasca or Skirk continuation. |
| Empty cooldown queue `workerStartedAgo` | Omit only when that action's queue is empty; keep charges, queue, worker-presence flag and any worker callback gap. | `internal/template/character/cooldown.go` reads the worker start for a nonempty queue's remaining time; `SetCD` starts a new worker and overwrites it on an empty-to-nonempty transition. |
| Global status entries with expiry `<= current frame` | Omit expired entries. | `pkg/core/status/status.go` uses `>` for Duration/Add's live branch and `<=` for Extend's no-op. Equality is already expired for these gameplay reads. |
| Infusion with expiry `< current frame`, except permanent `-1` | Emit an expired slot without stale key/tags/expiry. Preserve expiry `== current frame` and permanent state. | `pkg/core/player/infusion/infusion.go` returns early from Extend for `<`, while `WeaponInfuseIsActive` treats the equality frame differently; `-1` is an explicit infinite sentinel. |
| Completed animation `characterIndex`, `lastAction`, `stateExpiryRemaining` | Omit when `aniEvt == nil`; retain `startedAgo`, idle state and active flag. | `pkg/core/player/animation/animation.go` uses the old character/action/expiry only while an action is active; `CurrentStateStart()` still returns `started`, and Raiden/Minazuki read it. |
| Player `lastStaminaUseAgo` above 90 | Fold to 91; keep `<=90` exact and negative ages exact. | `pkg/core/player/player.go` regenerates stamina only if age `> StamCDFrames` (90). Xilonen saves/restores the stored frame but does not branch on its old numeric value. |
| Expired Verdant Dew deadline | Fold negative remaining time to `-1`; preserve zero. | `pkg/core/player/verdantdew.go` returns when expiry `< frame`, but processes the `== frame` boundary. |
| Expired stamina/shield-bonus modifier deadlines | Fold negative finite remaining time to `-2`; preserve `-1` permanent and zero equality. Retain entries in original order and their callback gaps. | `pkg/core/player/stam.go` and `pkg/core/player/shield/bonus.go` use finite expiry comparisons; old entries can affect future replacement order, so only elapsed magnitude is folded. |
| Player `LastAction.UsedAt` | Omit; retain Type, Param and Char, plus character normal counters. | No gameplay reader of `UsedAt` appears in the inspected source. Several character action paths read Type/Param/Char, and normal-counter reset affects later attacks. |
| Character modifier expiry, dash cooldown, shield expiry | Preserve exact relative values. | Character `StatusExpiry()` exposes stored modifier expiry to character/weapon code; `pkg/conditional/character.go` exposes active-character dash expiry numerically; Lanyan's shield refresh copies an existing shield's `Expiry()`. |

These exports remain observations. Pending callbacks, concrete character/weapon/artifact private fields, and modifier amount closures continue to appear in the `gaps` list.
