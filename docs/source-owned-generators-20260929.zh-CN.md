# 来源归属的有限技能伤害与持续协同任务

本报告记录 109 批次已接入的有限伤害来源规则，以及三个由技能状态持有、但可能由后续动作触发的持续协同伤害族。它描述的是固定来源版本中可审阅的执行范围，不是游戏内实测或对整套技能效果的证明。

## 口径与证据边界

有限技能总伤害只在当前动作调用、技能身份、原生任务生产链、派发和目标终态均能由同一运行记录闭合，并且集合中的固有命中全部纳入共享计算时显示。固定次数规则显示预期与完成数；次数由原生任务决定的规则在闭合前显示实际观察到的根攻击数和待处理状态。攻击数代表排队攻击机会，不等于命中数；已观察未命中与尚未结算也分别记录。

持续协同规则另以确切状态实例建立技能归属。技能创建的状态、后续动作触发的协同回调、回调排队的伤害、状态结束是分开的来源证据。只有来源审阅过的生成器、触发点和攻击发出点进入技能固有伤害范围；任务执行完毕本身不证明它产生的每次攻击都已派发并应用。

计算仍复用逐击共享公式、可编辑命中和公式追踪；有限技能集合也可在独立计算器中打开、修改命中纳入状态并导出 JSON。这里的“完整”只表示下文固定源码契约范围内的固有伤害记录闭合，不表示游戏内验证、DPS、整套技能所有效果或实战表现。独立反应伤害、武器／圣遗物追击、后续动作自身伤害、其他队伍伤害、治疗、护盾与持续增益仍需各自的归属证据。

## 新增的 11 个固有伤害族

下列六项来自有限技能批次 A，五项来自批次 B。两lane原生构建通过；只有夜兰持续协同族有本批新增浏览器运行样本。

| 角色与动作 | 可闭合的来源范围 | 关键条件与边界 |
|---|---|---|
| 艾诺 E | 缪斯捕手两段固有水伤 | 两个来源注册任务及两次攻击均需结束；不把 Q 状态下的 C2 攻击或反应、装备伤害并入。 |
| 夏洛蒂 Q | 初击与八次留影机伤害 | 初击及八个场地任务的派发、应用均需闭合；治疗分开，C6 后续普攻／重击触发不归入 Q 固有攻击。 |
| 辛焱 Q | 初击与七段火焰 | 仅 C0–C1。C2 及以上的额外脉冲、三级护盾及其 DoT 未纳入，因此不能据此声称 C2+ 完整 Q。 |
| 香菱 Q | 三次起手与旋火轮固有伤害 | C4 前后按来源任务确定九或十二个旋火轮任务；源码将约 73 帧间隔及命中框标为近似，不据此声称实机频率。 |
| 柯莱 Q | 爆炸与状态驱动的跃击 | 不预设跃击次数；必须等跃击生产链结束且没有后继任务。相同 Q 重施可能覆盖共享状态，故重施前需闭合。 |
| 枫原万叶 Q | 斩击与五次领域跳 | 吸收追加击数取实际来源状态；重施会覆盖共享吸收与快照状态，需在重施前闭合。 |
| 神里绫华 Q | 切割与最后绽放伤害 | C0–C1 为 20 个排队机会，C2 及以上为 60 个；计数是机会，不是命中或反应次数。 |
| 琴 Q | 初击、入场／离场及领域结束伤害 | 次数随有效整数 `enter` 参数变化（至少一次）；治疗与自身扩散是独立组件，不计入敌方固有伤害。 |
| 早柚 Q | 初击与不倒貉貉任务伤害 | 运行时根数为 1–7；每个任务是否排队攻击取决于实际敌我生命状态及 C1 条件，治疗、粒子、扩散及 E 分开。 |
| 珊瑚宫心海 E | 化海月固有伤害 | 按首段及状态持续期间实际生成的任务计数，不假定固定七跳；同角色 E 重叠会因共享状态被拒绝。Q 状态可能延长持续链。 |
| 绮良良 Q | 箱子与猫草豆蔻固有伤害 | 初始豆蔻为 6 枚，C1 生命条件最多增加 4 枚；`hits` 缺省使用原生默认 2，或显式提供整数 `>=0`，更大值由原生按豆蔻数截断。`mine_delay` 仅接受缺省值或 180 帧，以保持审阅过的任务顺序；攻击数由实际任务结果确定，不推成固定命中数。C4 后续攻击及无关部署物排除。 |

边界参照：瑶瑶 E/Q 的机关 `OnThink`、击杀与切人事件缺少闭合所需 ABI；琳妮特 Q 的吸收追加击缺少因果来源证明；卡齐娜在当前固定来源树中没有角色实现。这些不纳入完整技能合同。琳妮特可审阅的固定风属性组件不能称为完整 Q。

## 新增的 3 个持续协同归属族

| 技能状态 | 归属方式 | 计入的协同攻击与限制 |
|---|---|---|
| 行秋 Q 剑雨协同伤害 | 绑定 Q 创建的精确状态实例；通过状态变化或 ticker 触发 | 按成功触发当时的剑数计入 2/3/5 次剑雨协同伤害。E/Q 共用雨帘剑接触附着、回能和抗性变化不作为独立 Q 固有攻击。 |
| 夜兰 Q「玄掷玲珑」 | 绑定延迟建立的骰子状态实例；通过状态变化、ticker 或 E 命中触发 | 每次触发计三次协同攻击，C2 条件满足时另计实际追加击。Q 状态要到来源任务运行后才创建；E 命中途径不要求套用 Minazuki ticker 的 ICD。A4、C6 后续普攻改变及其他非固有伤害不并入。 |
| 托马 Q「炽火大铠」 | 绑定 Q 创建的精确状态实例；通过状态变化或 ticker 触发 | 每次成功触发对应一次烈焰崩破攻击。生成护盾回调、C4 回能与 C6 伤害加成属于其他效果。 |

这些状态由 Init 注册的监听器维持；监听器存在不代表 Q 状态仍有效。归属必须匹配实际状态实例和明确触发记录，保留原来的创建动作与触发动作来源，不把后续普攻／技能改写成 Q 创建。状态被替换或到期、所有已记录触发完成、每个已排队攻击有派发和每个检查目标有终态，才可能闭合该协同伤害范围。Xingqiu 的 hitlag 可能延长实际到期；Yelan Q 状态创建前、状态终态未知以及未结束的攻击都继续保持未闭合。

这不等于该角色所有技能效果均归属 Q：行秋 E/Q 共用轨道，夜兰 A4/C6 与托马护盾等效果有独立生命期或触发路径。工具只承诺标记过的来源发出点与攻击，不以回调期间偶然出现的攻击自动归入。

## 声明 JSON 与旧记录

合同声明继续使用版本化的源码规则清单。既有固定根攻击数与参数分支规则保留；新增有限技能可声明任务生产点、父子任务关系、运行时攻击数条件及闭合条件；持续协同合同另声明状态创建点、触发点及允许的攻击发出点。声明仍需绑定普通／星辉来源提交及审阅文件哈希。

每次运行的集合 JSON 保留已接受动作、命中编辑、包含选择、观察任务及有限技能证据。持续协同记录通过可选生成器与触发行保存精确状态实例、独立触发来源、实际排队攻击及状态终态。有限集合可使用 `skill-ownership` 关联；此前的 `creation` 有限集合仍兼容，普通观察集合继续使用创建、触发、状态归属三种观察关联。旧 JSON 缺少任务或状态实例证据时不会补造记录，也不会从动作名称、经过时间或空任务队列推定闭合；仍按可证明的小计处理。导入后按当前共享公式重新计算。

## 验证状态

本批注册表核对为 35 项：26 个 producer 声明行与 10 项原合同合并，Bennett E 的统一按压／蓄力合同去重 1 项。Xiangling／Kirara 两次初始补丁因引用插桩后行号未匹配；改为从插桩前来源生成统一 diff 后，最终 Classic 与 Stellar 原生构建分别 8.022 秒、8.473 秒通过。初次 typecheck 发现 `skill-ownership` 误经普通关联选择器，已在动作选择处拒绝该路径；最终 `npm run build` 4.915 秒通过，天赋注册表生成 0.157 秒通过。声明与分析聚焦测试 2/2（2 文件，2.214 秒墙钟；Vitest 1.70 秒）：一个测试回归四份旧捕获，另一个测试 Venti 合成结构终止条件；均未新增 native 执行。

唯一浏览器案例通过（用例 12.5 秒、runner 13.7 秒、墙钟 14.185 秒，`pageErrors=[]`），是一场 Classic 夜兰 C2 Q 团队运行，观测到 1380 帧（23 秒）。同一 Q 状态实例在第 77 帧激活、第 977 帧结束；状态变化、ticker、技能命中共触发 9 次，32 个归属应用的小计为 28378.67210456749，32 项共享公式重放差均为 0。native 团队总伤害为 34526.939080662196，其中 10 个凯亚普攻和 1 个夜兰 E 自身命中未归入 Q 归属小计；集合导入／导出一致。离线负例通过删除触发回执、改为状态仍有效，均不判完整，并非额外 native 短窗口运行；另有一个已完成但产生零攻击的 producer。以上仅证明该固定来源版本与团队输入下审阅范围可复算，不是游戏验证、角色全覆盖或全部技能效果闭合。

除夜兰 Q 的这一场运行外，全部 11 个新增有限技能族以及行秋 Q、托马 Q 两个持续协同族，在本批只有源码审计、合同／构建证据，没有新增 runtime 样本。它们不能被解读成逐角色实测覆盖。
