# 固定来源共享移动与交换状态（122）

## 本批实现

本批为动画排队回调增加与回调同生命周期的可选 phase 描述符。回调与描述符存于同一队列项，排队时保留原始延迟和来源身份；执行或移除队列项时，观察元数据同步消失。未描述的队列回调仍产生明确缺口，不把“已排队”误作可解释状态。

角色交换帧规则读取当前 `Delays.Swap`；交换回调描述符读取实际目的角色键及其当前角色索引。活动角色、冷却、冲刺状态和角色计数由已有 player／character provider 表达。描述符不运行交换回调，也不更改原生交换时序、冷却记账、普通攻击计数重置或事件顺序。由于交换动画通常在 `CanQueueAfter` 到期时已完成，观察器未捕获待执行交换项：两 lane 的 swap frame 与交换完成队列描述符在本次运行中均为 0。

共享移动与体力描述符覆盖默认 Dash、Walk、Jump 帧规则及延迟的冲刺体力消耗任务。观察器复制原构造点已选中的帧值，不额外查询 Stat 或重跑帧回调；延迟体力任务以新键 `dash-stamina-consumption` 注册，观察时复制其当前参数（包括 nil），保留原任务延迟与执行顺序。Stellar 的动态 Jump 分支保留运行时 `JumpModified`／Airborne 条件，并在观察时读取相应实时状态；Classic 普通 Jump 与固定 airborne 分支仍描述原始选择的帧值。配置中的跳跃标记在 Classic 为 54 帧、Stellar 为 27 帧，lane 差异保持原样。

另增加共享延迟冷却起始描述符，记录角色索引、动作及原始时长；原回调和延迟保持不变。该分支本次场景没有触发，只具源码与构建证据。`AbilStamCost`、`UseStam`、体力 modifier 回调及事件仍只在原生执行时工作；自定义角色移动实现与 modifier 不会因本描述符而自动完整。

## 实际验证

Classic 与 Stellar 来源构建分别用时 6.510 秒、6.857 秒；队列生命周期定向测试各 1 项，分别用时 3.408 秒、3.558 秒；最终 typecheck 2.650 秒，Web build 1.068 秒。每 lane 的原生测试仅覆盖通用队列描述符的加入、观察和生命周期，不等价于观察交换进行中的浏览器状态。

浏览器只有一个聚焦场景，共 4 次尝试、4 次原生运行。最初测试种子格式无效，未启动原生运行；之后一次失败源于把芭芭拉误当作默认 Dash 帧规则（她使用自定义帧表），修正后复用 Classic 捕获，仅新跑 Stellar。最终同配置、同 seed 的前后对照在两 lane 均于 175 帧结束，记录 6 个 phase 标记、34 条 action log、1 次命中（45.39786424509601）。逐项比较的命中、移动日志、phase player state 与标记帧均一致，页面错误为空。

观察到每 lane 两项 Walk 描述符、一项 Jump 描述符及一项待执行冲刺体力任务，剩余 18 帧；没有观察到默认 Dash 或待执行交换描述符。未知缺口由 35 降至 33，但两 lane 的 complete boundary 均为 0，也没有提出收敛结论。最终结果和原始捕获见[测量汇总](validation/source-shared-movement-measurements-20260930.json)、[浏览器结果](validation/source-shared-movement-state-20260930.result.json)与[捕获](validation/source-shared-movement-state-20260930.capture.json)。

## 范围与限制

源码基线为 classic `b4ae769d7c1c1bce68fce5faf0b460c5b5b7f541` 和 Stellar `a7dc4bf4f5e18390035ca0333fb6eb1d5fac32bd`；移动、队列与体力源码边界见[审计记录](validation/source-shared-movement-audit-20260930.json)。本批没有运行完整角色或帧测试矩阵，没有完整验证动作所有权或 steady state，也没有更新数据目录、晋升预览／正式指针或进行游戏内核验。源码描述符、单一浏览器场景与通用队列测试都不证明完整角色动作或全局 phase 已闭合。

主目标仍有五类剩余工作：更广动作的来源执行、完整技能生命周期、角色私有状态与回调的相位闭合、远端持续更新的实际运行证据，以及下一版本数据映射与来源核验。本批完成了可实施的共享状态改动，没有将这些代码缺口或外部证据缺口标为完成；独立单击／单技能计算器继续保留为产品入口。
