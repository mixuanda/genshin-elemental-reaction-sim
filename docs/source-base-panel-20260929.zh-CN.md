# 固定来源初始基础面板回放（2026-09-29）

本批把原生角色／武器初始化得到的基础面板配方接入共享公式树，并在来源属性读取凭证中可选保存这份配方。它解释的是初始化层，不是战斗最终面板或角色机制覆盖率。

`source-host-base-panel.ts` 重放初始化实际配置向量，按来源顺序计算角色与武器等级曲线索引、目录基础值乘曲线、突破行、默认值和其他目录属性。步骤保留原生 `set` 与 `add` 语义；武器基础攻击等覆盖写入不会被误作累加。记录包含实际选中的突破行及最大等级、身份与等级、输入向量、中间角色／武器向量和最终向量，执行时核对各步和最终结果。目录值仍是固定来源输入，不据此声称独立游戏验证。

属性读取的 `basePanel` 是可选 receipt，限定 actor 与四种面板 getter。读取及嵌套依赖可复用同一记录；共享 provenance 图把面板最终值连接到 getter 前实际值。两者有差异时只记录观测到的差值，不逆推中间修改机制。没有 receipt 的历史读取仍保持上游不透明。界面可显示根读取与依赖 actor 的身份、输入来源、步骤数和向量；编辑最终面板会保留原始初始化历史。

`configured-stats` 是原生初始化收到的配置属性增量。`sampled-stats` 保存实际抽到的向量，但随机副属性抽样仍属于外部输入；配置标签沿用配置器标签，不推断某条标签就是一件圣遗物。角色／武器后的战斗修饰器、成长状态、完整技能语义及跨帧机制不在此初始化配方范围内。

固定来源样本中的行秋基础攻击可作一条具体数值链：角色目录基础攻击 `16.9176 × 8.349 + 60.53229 = 201.77733240000003`；武器基础攻击 `41.0671 × 7.275 + 155.6 = 454.36315250000007`；两者相加为 `656.1404849`。该击的下游输入再计算为 `656.1404849 × 1.24 + 200 = 1013.614201276`。这些是 pinned source 的目录、曲线与配置输入回放，不是独立游戏验证。实施前审计的示例编号 #10 在46帧对应 `Guhua Sword: Fatal Rainscreen 0` E 首击，详见[历史来源与时序审计](source-panel-provenance-next-20260929.zh-CN.md)。

最终页面抽样在 classic／stellar 两lane各有102次计算和38次伤害应用，gameplay 字段与不可变基线一致。两名角色面板均包含11个角色构造步骤、3个武器构造步骤；应用编号11（第46帧）重放差为0，生成112个基础面板公式节点，保存classic／stellar来源捕获并通过JSON往返。最终 core 单测2/2通过；classic／stellar构建19.292／19.887秒，Web构建8.551秒，聚焦页面用例通过（运行18.2秒、总墙钟18.847秒），页面错误为空。随后仅修正空标签显示文案并通过Vite bundle（2.397秒），没有重跑typecheck或E2E。首次核心与Web/E2E失败均留有日志：核心修正了共享builder快照问题；Web修正了UI字段接线；E2E把选择器限定到可见来源命中和独立计算器编辑器后重试通过。详见[验证测量](validation/base-panel-measurements-20260929.json)。
