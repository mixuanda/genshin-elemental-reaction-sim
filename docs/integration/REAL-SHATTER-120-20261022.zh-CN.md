# 真实碎冰队120秒及Q能量验收

基线 d3f899f，继续同一云 integration 分支。保留三人原合法构筑：90/90 C0 T1凯亚/芭芭拉/诺艾尔，R1飞天御剑/异世界行记/白铁大剑，五件+0、五种不同套装、无套装加成。没有新增圣遗物数值或能量注入。初能仅用已实现的零能/满能初始化开关。

脚本为原生 `while 1`：凯亚E；仅当 `.kaeya.burst.ready` 实际满足时释放Q；芭芭拉N1；诺艾尔未开Q的物理钝击N1；等待360帧，再逐轮重验冷却与能量。不能以短轴结果乘次数。脚本、分件配装、原生返回与实际检查代码均保存。

## 约束、数值、归属

- 初始化回执逐角色验证零/满能。所有能量应用从初始状态逐笔重建：before等于上一after；粒子按元素、前后台、三人队系数和实际ER独立计算；应用按上限截断，消费必须凯亚有60能量并扣60；无flat-change注能。粒子算术最大误差0。
- 每次E/Q都检查实际起手间隔与固定冷却；离线对照原生日志验证E起手+25帧触发360帧CD，Q起手+48触发900帧CD、+51帧实际扣能，恢复帧也逐条匹配。native auto-wait保留动画/切人限制，不伪造命中时点。
- 全部410个伤害应用验证整数帧、真实应用帧与请求帧一致、处于[0,7200)。碎冰由诺艾尔真实父普攻连接，同帧子碎冰先结算，起手到命中27帧；每个attack/target仅一次应用，零伤害Freeze Broken保留。离线另确认全部56次碎冰前均有上一次碎冰之后的新Hydro→Frozen事件，未借用旧冻结记录。
- 全部应用独立算术：碎冰 `1446.8535×3×(1+16×28/2028)×0.9=4769.479792011834`；普通/凯亚Q使用真实快照攻击、固定T1倍率1.912/0.776/0.3784/0.7912、0.5防御、0.9抗性及实际暴击。最大伤害误差0。另选每条6笔代表命中，通过已有独立计算器捕获重放，24笔差均0。
- 逐角色应用求和、原生角色统计求和、团队total_damage三方守恒。详细贡献及每击预期/实际值见各summary.json。

## 显式增益与快照范围

同一把飞天御剑在本轮Q后触发固定来源已实现的R1攻击+12%，基础圣遗物攻击7%时快照为19%；无增益时仍为7%。验收逐次核对原生skyrider修饰器记录与此数值，没有手工永久Buff。凯亚Q各冰棱共享本次Q起手快照；动态E在增益失效后回落，不用当前面板替换旧Q快照。

固定上游Kaeya Q模型仍有明确近似：三个冰棱按40帧错开、各120帧循环，本例每Q记录13次命中；源码注释说明游戏可有14/15次，config中Q起手碰撞还标未实现。因此本报告证明固定来源的能量、时序和数值自洽，不能称官服Q完整精度或全部机制完成。没有引入诺艾尔Q或其他未验证增益。
