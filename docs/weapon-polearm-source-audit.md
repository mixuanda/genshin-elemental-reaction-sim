# 长柄武器条件规则增量

本批增加 19 把长柄武器的独立计算器条件条款。所有规则仍为 `provisional`、`conditioned-snapshot`，包含部分被动映射，不代表 19 把完整被动或自动队伍模拟已完成。真实角色基础面板、精炼、武器属性与条件 AST 一并进入共享计算核心；UI 不预先折算平值。

固定来源是 genshin-db `49a6544a6c6ae36089cb42fa591fc46f01de8bcf` 的活动 7.1 目录、gcsim `b4ae769d7c1c1bce68fce5faf0b460c5b5b7f541`，以及 Genshin Optimizer `180a0a1015cb725c7570cd828eb086749960df98` 的实际武器 sheets。原始 UTF-8 文件、许可证、URL 与 SHA-256 保存在 `packages/game-data/sources/weapon-polearm-effects/`。登记时逐项核对全部 R1–R5，不从端点补猜中间精炼。

验证集中于本轮统一新增测试文件 `equipment-weapon-expansion.test.ts`：首轮 131 项中 130 通过，仅一个浮点深相等断言失败；改为容差后只重跑该项并通过。完整命令与时长见 `docs/weapon-expansion-implementation.md`。单独模块未运行旧测试、全套构建或浏览器矩阵。
