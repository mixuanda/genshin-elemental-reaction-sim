## 实际接线

- `weapon-additional-effects.ts`：固定精炼文案与数值逐项匹配，输出属性／伤害 AST，覆盖铁蜂、万国、千岩双武器、螭骨、斩岩、白影、若水、冬极、匣里日月、断浪家族、有乐、波乱等 33 项。完整列表、手列数值与未执行条款见[武器记录](weapon-additional-effects.md)。
- `artifact-additional-effects.ts`：26 套普通属性或伤害条件，以及影中沉凝经典超导 +80% 的反应专用条款。覆盖生命门槛、前置目标附着、已有效护盾、独立时长窗口、层数、同／异元素队友人数、月兆和魔女资格。逐套公式与触发边界见[四件套来源审计](artifact-additional-source-audit.md)。
- `equipment-build.ts`：真实装备分派、源贡献合并、缺失条件门禁、明确来源冲突及覆盖并集计数；额外套装协议不会重复叠加两件套。
- `equipment-formulas.ts`、`artifact-conditional-effects.ts`：按所选武器及真实件数提供条件控件定义。严格文档 schema 由主任务接入 13 个新字段；元素集合控件由主任务 UI 接线。没有新增独立算术核心。

烬城基础 12%／15 秒与夜魂额外 28%／20 秒是两组独立元素集合，允许只有 28% 的尾段。磐岩限一种火／水／冰／雷元素；天赐秘仪下至多两个不同固有元素，同元素不能加为 80%。这些集合保留在文档中，由共享核心按命中元素筛选，不在 UI 中改成手填总增伤。

黑曜四件套 40% 暴击窗口与二件套“当前夜魂加持且前台”的 15% 增伤独立。匣里日月两个 6 秒窗口也独立，仅普攻及战技／爆发对应生效，重击不受益。断浪家族由共享 AST 执行 `min(精炼上限, 队伍能量上限总和 × 每点加成)`，没有恢复能量或验证循环充能的含义。

## 证据与阻塞

圣遗物归档 83 个原始来源文件、403,444 字节；武器归档 87 个原始来源文件、315,717 字节。归档包含固定 URL、SHA-256、许可证及来源用途，来源为固定 genshin-db `49a6544`、gcsim `b4ae769`，部分新套装使用 GO `180a0a1` 的实际 sheets，排除其 TODO 模板。

以下边界没有被隐藏或猜测：

- 战狂恰好 70% 生命：目录为 `<70%`，固定源码为 `≤70%`，拒绝该冲突边界。
- 试作星镰：目录普通／重击增伤与固定源码 ATK% 乘区冲突；神乐：持续时间、星超导及错误物理增伤冲突。两把均未计入本批可执行覆盖，实际配装显示冲突来源。
- 魔导绪论的纯冰／冻结不匹配分支冲突，阻止推测。无垠蔚蓝、四风、遐思等参考实现存在触发或计时差异，仅恢复已确认状态。
- 生存、移速、攻速、体力、定值能量、额外攻击、概率历史、全队传播及同名效果事件去重没有因数值映射而标记完成。
- 穹境／纺月的月曜反应奖励、血红／炉火的星反应奖励，以及影中沉凝目标专用暴击等仍独立列为阻塞，未混入普通增伤。
