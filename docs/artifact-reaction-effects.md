# 装备反应系数与敌人减抗

`artifact-reaction-effects.ts` 执行翠绿、深林、如雷和魔女的已核对常规条款。`reactionBonuses` 与 `resistanceReductions` 是独立结构，共享核心逐命中按真实反应和伤害元素筛选并执行公式；没有将两者转换为普通 `damageBonus`。

- 翠绿：四种普通扩散的反应奖励0.60；火、水、冰、雷分别保留来源减抗0.40和显式有效状态。当前目标可同时存在不同元素状态，同名同元素不重复叠加。触发时需要装备者前台，已存在的减抗不因随后退场而立即失效。
- 深林：当前目标草减抗0.30，使用明确8秒窗口状态。战技或爆发命中触发不限伤害元素，允许后台触发；输出只影响草伤的抗性步骤。
- 如雷：超载、感电、超导、超绽放的反应奖励0.40；超激化加算基础的反应奖励0.20，不包含蔓激化，不把整次普通命中乘1.20。
- 魔女：超载、燃烧、烈绽放反应奖励0.40；正／反蒸发、正／反融化奖励0.15。该常驻条款独立于原有0–3层火伤，零层也适用。两种条款分别执行一次。

界面使用原有布尔控件恢复 `vvPyroResActive`、`vvHydroResActive`、`vvCryoResActive`、`vvElectroResActive`；深林使用 `setEffectActive`。未知不等于否，明确启用却未提供必要状态时拒绝应用。未生效的减抗仍保留源值及 `active: false`，轨迹执行「源减抗×状态×元素资格」，而不是将来源改写成0。条件计算不生成触发、传播、持续时间、到期或卡肉事件。

固定来源与许可、全文、SHA256见 [来源审计](artifact-reaction-source-audit.md) 及 `packages/game-data/sources/artifact-reaction-effects/manifest.json`。四份套装实现与抗性覆盖代码、MIT许可共7份原始文件保存在项目内。

当前7.1翠绿另有星扩散20%及对应冰减抗路径，固定参考实现未提供这些星反应标签／事件；如雷星超导同样缺少对应实现，继续阻塞。如雷月感电20%已有固定源码证据，但直接／间接月感电的装备归属尚未接入本次普通反应协议，因此保留独立缺口，不将它误算为普通感电。如雷减冷却仍未自动调度，未添加任何回能。所有结果仍为 `provisional`。

执行 `npx vitest run packages/game-data/src/artifact-reaction-effects.test.ts`：5项通过，917 ms（执行18 ms）。四个来源用例核对精确反应集合、倍率、减抗元素／状态、停用及未知条件；真实翠绿配装集成用例核对普通火扩散0.60、10%敌抗−40%=−30%、未激活水抗仍10%、完整JSON及导入最终面板结果等价。本轮没有重复全部装备或核心测试。

四件套条件覆盖从14种增至17种：新增翠绿、深林、如雷；魔女是在已有条款上补全常规反应部分，不能重复算作一种新套装。覆盖清单已由现有生成脚本更新。
