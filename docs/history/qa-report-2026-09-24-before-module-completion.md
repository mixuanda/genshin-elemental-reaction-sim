# 当前实施与验证报告

更新：2026-09-24。本轮接入笛剑、以理服人、流月针和竭泽的独立计算、真实生命周期与确定性周期状态。最终 goal 保持进行中；全游戏机制仍未完成，未提交、推送或部署。

## 实际变化

永久独立计算器累计12把追击武器／60个精炼位置、75个条件分支。本轮新增20个精炼位置，无需队伍、轮转、五音符、战技窗口或拾球记录即可计算一次明确已经触发的追击。面板与精炼可编辑，来源系数由共享核心重建；每个适用节点保留公式、变量、数值代入、中间结果和解释。次数、触发间隔与概率不乘进单次伤害。

团队运行使用实际事件：笛剑通过本人前台普攻／重击回调获得音符，30帧音符门限、1800帧刷新窗口，五音符产生一次独立追击；以理服人的实际战技开启900帧窗口并清命中冷却；流月针在真实粒子／晶球分配后，按当时前台激活300帧窗口，满能和零数量的实际接收仍可激活，固定回能不能代替拾球；竭泽实际战技受720帧激活冷却，900帧窗口内最多三次，第三次删除效果但保留已经排出的伤害。流月针命中时不复查前台，也没有额外命中冷却。

新四把在实际同相位FIFO回调取样，+1帧独立结算；范围半径分别为4、3、单体和2.5。生命周期账本引用真实动作或粒子事件，伤害回调保存前后状态。结果校验从已接受动作、来源绑定的真实拾取和普通伤害回放，不能凭导入日志自行补音符或开窗口。完整命中捕获复用同一来源倍率AST和最终数值输入。

实际检查点捕获音符、效果与激活时钟、次数、待回调和待命中的历史快照／几何／FIFO。到期等号保留剩余0；仅在未来行为等价时归一已经失效的计数。原生普通Aura闭合域可以证明这四把的确定性周期；五把随机追击的完整随机周期仍阻塞。

## 发现并修复的实际问题

连续检查发现合法增益`atkFlat`写入了与公式不同的字段，+200攻击未生效，窗口只有1800伤害。当前合法帧运行现明确将`atkFlat/hpFlat/defFlat`映射到`flatAtk/flatHp/flatDef`，结果重放和召唤快照重放同步处理。新增`flatStatBuffSemantics: canonical-v1`进入完整运行身份；旧当前记录缺此标记时保持历史读取，旧版本拒绝新标记，legacy模式不改变。原夹具未换成百分比增益绕过，修后窗口1880；直接实测的是攻击分支，未因此声称动态最大生命值支持。

当前粒子配置也允许真实0数量及包含0的数量范围，旧版本正数限制保留。首轮运行夹具揭示该入口无法表达来源中的零数量接收，修正后实际0粒子、满能拾取仍能激活流月针；没有把0改成1掩盖问题。
