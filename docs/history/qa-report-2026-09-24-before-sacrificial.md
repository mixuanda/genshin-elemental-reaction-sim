# QA 与实测报告

更新：2026-09-24。本轮实现讨龙英杰谭的真实切人增益、独立计算器逐击记账和完整确定性检查点。独立单击／单技能入口仍无需队伍或轮转。完整 goal 继续进行；未提交、推送或部署。

## 实际变化

讨龙 R1–5 的24/30/36/42/48%攻击百分比、600帧增益和1200帧持有者冷却共用固定来源定义。独立计算器可填写外部提供者、精炼、每击实际生效状态、输入ATK已含的旧精炼份额及接收者白值，执行 `基础ATK ×（实际比例 − 已含比例）`。它与角色自身C2等攻击调整并存，不覆盖另一条公式，也不因为接收者自己装备讨龙而给自己加攻。

实际份额与已含份额相同则差0，不索要未知白值；不同则明确要求白值，不从最终ATK反推。负差可以扣除已失效或更高旧精炼份额。每击独立依赖，未选命中的未知状态不阻塞单击。来源配装白值、手动共同白值和历史快照自己的白值分别使用；转最终面板后共同白值仍可编辑。重新配装或导入只重置当前面板的记账，保留未被替换的历史快照条件。正常表单、共享公式逐步解释和JSON均已接入。

团队页显式声明真正的讨龙持有者与精炼，不改基础伤害面板。实际从持有者切给另一角色时，先检查并消耗该持有者冷却，再检查接收者共享ttds增益。已有时不刷新、不替换、不叠加，也不退还冷却；领取后切下接收者不删增益。合法轮转由已完成swap触发，旧式动作实际改变前台则明确标记legacy-implicit。

来源有两个不同边界：数值在600帧到期时失效，而状态存在性在相等帧仍可阻止刷新；真正完整Stats取样会删除到期状态。实现独立保存这一存在性，只在实际攻击取样等已接入节点清理；查看报告、检查点、空切人或单属性查询不制造完整取样。持有者1200帧冷却相等时仍有效。

真实领取／拒绝账本、接收者和持有者期限、动作身份、命中快照与公式进入结果页、分析窗口和完整记录。动作／召唤的历史讨龙标签随实际待执行载荷保存，不能被交付时的实时增益替代。结果校验独立重放状态与实际属性贡献；计算器恢复展示已经包含的来源份额，不再叠加。

完整相位状态捕获真实持有者冷却、接收者存在性、当前增益及在途快照，保留相等到期的剩余0。没有从日志构造运行时状态或为了冷却增加尾部等待。固定来源安柏、诺艾尔及久岐忍示例仍检查其原武器身份；一个角色不能同时声明讨龙、西风或独立追击武器。
