# 已知限制与未完成依赖

更新：2026-09-24。以下边界按本轮实际代码同步；本次文档同步未运行测试。主提示要求的全游戏机制覆盖尚未完成，最终检查结果以 [QA 报告](qa-report.md) 为准。

## 数据与版本

- 官方版本观察、活动元数据目录、已验证数据集互相独立。当前 7.1 正式发布观察来自2026-09-23，对应目录为 released/provisional；本次机制更新没有重新观察官方版本，目录激活不等于正式验证晋升。
- 新来源候选不会自动替代活动数据，旧包也不会由本地 CLI 远程热替换。精确目录身份、来源时间、候选和覆盖数量由 [更新状态](update-status.md) 从活动快照生成，不在本文复制易失效的计数。
- 尚无完整依赖均验证并正式晋升的数据集。独立名册已建立分类核对，整体仍为 partial，尤其武器总分母及任务变体口径保留边界；不计算「全量完成百分比」。身份记录、天赋形态、有条件动作和完整可执行角色不是同一种计数。
- 7.2 V1 未取得可下载、可固定版本和可复核的结构化快照；不创建空的成功预览，也不把缺失字段填零。
- 角色、武器、圣遗物、命座文本与曲线可浏览，不等于全部被动、触发和状态转换已可执行。有条件可计算定义与 verified 定义分别统计；固定来源复现不自动成为当前官服独立验证。

- 基础动作已含十五名角色的已审分支，按每次输入保留多击结构和明确的 E/Q关闭、无附魔、零层数等条件；钟离已解锁的每击生命附加不会被“C0”条件抹掉。后续第三批实际补入25个条件动作、30次命中：八名角色的低/高无碰撞下落、芙宁娜N1–N4的始基力冷却中/就绪分支，以及艾尔海森全程零镜且A1冷却覆盖全部回调的双段CA。芙宁娜就绪N包含水追击，冷却中分支仅物理主击；水追击按固定来源不附着且不反应，不能把它当普通水伤。合法腾空、外部下落加项未生效及状态稳定均是显式条件，不等于动态轮转或体力已实现；海森有镜/A1就绪、魈Q下落等仍需独立分支，见 [基础动作缺口与映射](cross-validation/basic-attack-gap-audit.md)。烟绯条件重击与A4另按下文入口执行，不代表其完整时间线已补齐。
