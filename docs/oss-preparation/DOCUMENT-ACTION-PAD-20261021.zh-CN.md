# 新格式与点选动作面板：本地可交互版本

云工作目录 `/workspace/GIDPS-cloud/latest`；分支 `cloud/ci-provenance-20261020`。基线 ba86a15。无 push、合并、部署、根许可证或凭据改动；未修改／重建 WASM。

## 打开与操作

已构建。可在该目录运行：

```
npm run preview --workspace @genshin-dps-lab/web -- --host 127.0.0.1 --port 4173 --strictPort
```

打开 `http://127.0.0.1:4173/results`。这是本地预览，不是外部部署。

1. 在“行动编辑”底部展开“载入来源动作示例”，载入诺艾尔 Q→普攻；也可从“模拟结果”的导入按钮打开 `docs/fixtures/noelle-q-normal-reference.json`。
2. 清空指令后，在上方点选面板点 Q，再点当前核心允许的普攻。四槽用于查看已有队伍；查看不切人，另有明确切人按钮；空槽通向队伍配置。
3. 可以选 15/18/20/60/120 秒窗口。未接入动作明确显示不可用；来源或状态不允许的动作保留限制详情。面板不自行构造倍率、CD 或能量。
4. 冷却未好时显示真实核心试算等待和“等到可用”。用户点击后才把等待加入轴；能量不足说明来自执行回执。可撤销点选、删除或调整原有行动卡片，后续资格重新试算。
5. 点“快速计算当前完整时长”。原有结果页提供总伤、DPS、角色贡献与 1x/2x/4x/8x/16x 回放；倍率只影响播放。此轮没有重做播放或批量统计。

面板调用同一 Worker / simulate，逐个试算候选，不使用 UI 独立时钟。离开或修改面板会取消旧候选计算。这里是当前配置的动作编辑器，不是已完成全部角色机制的游戏操作器。执行延迟配置仍走原有预览／运行入口；新面板即时候选资格不额外应用执行延迟配置，最终运行的实际延迟以结果为准。

## 文件与协议

- `gidps-document-v1`：编辑输入副本。自动保存到本浏览器 localStorage；“本地副本”可下载，再由导入入口重开。不是悄悄改写磁盘原件。保存原件全文、显式运行选项及源输入；状态固定 `not-recomputed`。
- 打开旧文件不调用模拟。旧结果原文只读显示并可原样下载；没有独立源输入的结果不会被反推成新输入。必要输入缺失或无法证明原字段保留则拒绝转换。转换／存储失败不清空编辑器、不覆盖已有副本。
- `gidps-simulation-record-v2`：所有 UI 新运行记录的导出格式。普通既有结果标 `historical-reference-only`，不假冒新事件见证。适用的 nearby-wet EC 新运行使用 `event-steps-v1`。
- `gidps-event-step-result-v1`：有见证的结果，结果身份为 `1.54.0-event-steps`。解析先检查叶字段，再完整重放直接命中和 P5 分配／读取见证，最后运行原有全部跨日志／数值校验，仅将旧固定子步骤位置替换为已核见证的精确位置。共享 1.53 叶字段通过明确投影复用；旧 1.53 文件／解析器和默认 simulate 的历史契约没有更改。
- `calculator-event-v2`：携带完整新结果见证的独立命中捕获，支持计算器导入、重放和导出。旧 v1 保留。
- 不论输入编辑多少次，原结果都不会获得新验证。只有明确运行捕获了完整证据才产生新协议结果。导入的新证据显示“见证已校验，未重新模拟”，不宣称官服机制验证。

## 真实范围与限制

新协议正向覆盖有／无教官回调、有／无 Hitlag 的现有 nearby-wet-radius-v1 + target-phase-v2 场景；P5 内存见证还覆盖6／32目标的无水／超范围候选。缺失、篡改、顺序变化、跨归属及不认识的分配点拒绝，不接受任意编号递增。见证证明该固定引擎的记录一致性，不认证敌意改写整套输入与结果的真实性。EC 传播依旧 provisional，不标官方验证。新的执行延迟 profile 与 EC 组合未在本轮验收，既有 profile 基线仍使用历史 simulate，可能明确拒绝此组合。

诺艾尔浏览器验收使用仓库已存在的固定来源 b4 Q→普攻输入／预期值，属于 fixed-source-assumed。仅 Q 两击与 N1 一击，120秒窗口共3击：13.865514903092786、19.1476158185567、16.32499314185567。总伤49.33812386350516，DPS=总伤/120；没有把短片段复制成持续循环。此来源场景不支持E、重复Q、完整治疗／护盾／所有取消等，面板不补造。旧原生凯亚／那维莱特120秒循环成果未在此重跑或泛化到所有角色。

实测是 Linux Chromium，Windows 实机未测。四角色槽／A/E/Q 控件不等于四名任意角色均已支持。
