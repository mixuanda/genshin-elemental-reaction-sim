# 真实来源队伍批量模拟（2026-10-21）

本轮基于 ce054473。沿用已有班尼特／凯亚／香菱／砂糖 120 秒队伍、合法圣遗物与翠绿之影配置；没有加入角色或假设新的机制。输入在 `apps/web/e2e/fixtures/four-team-vv/vv.gcsim`，配装来源及合法性回执在同目录 `artifact-builds.json`，详细机制范围见 `VV-FOUR-TEAM-120-20261021.zh-CN.md`。

## 可操作功能

云端本地启动：`npm run build`，然后 `npm run preview --workspace @genshin-dps-lab/web -- --host 127.0.0.1 --port 4173`；打开 `/source-simulation`，在「真实队伍多次模拟」选择次数、1 或 2 个线程、起始种子、零能／满能、时间预算。运行当前配队或动作面板生成的脚本，不需要另写批量脚本。可取消、查看进度、导出 JSON。时间预算上限为一小时；超预算仅保留已完成样本，不能声称整批完成。建议先测 2–4 次吞吐。

此入口使用来源 Worker 的同一个 `execute`、Go/WASM 核心和共享公式回调，并继续执行完整结果校验。每个线程只初始化一次固定 WASM，每次 trial 重建原生 Core 和公式 resolver，保留完整连续 120 秒内的动作、冷却、能量、状态与反应；不是把短轴伤害乘次数。输出保存紧凑统计和事件 SHA-256，**不是可替代完整单次命中捕获的重放文件**。需要逐击公式时，可用导出的配置、某个 trial 的 seed 和同一执行器重跑单次。

## 随机性与统计契约

- 原生 `go-math-rand-rngSource-v1`，使用现有 uint64→int64→模数归一化规则。trial i 采用有效种子区间 1…2147483646 内按 i 递增回绕的序列；与线程数、任务总数无关，检查无重复有效流。每次重置所有模拟状态。不同初始化流不是数学独立性的证明。
- 本入口始终使用原生随机暴击及其他随机事件，**不是解析期望模式**，不再给已暴击伤害乘期望暴击倍率。旧 TS 批量入口和原生入口不混用 RNG seed 字符串。
- 统计窗口 `[0, configuredEndFrame)`。120 秒对应 `[0,7200)` 帧，DPS 除以 120，伤害汇总所有目标；精确落在 7200 帧的事件仍存在于原始引擎轨迹和事件哈希中，但不计入该统计窗。只有实际完成配置时长、原生随机性与执行器回执匹配的样本才成功。
- 归并按 trial index 排序，与返回先后无关。输出均值、样本标准差、标准误、p05／p50／p95；n≥30 才提供正态近似 95% 均值区间。分位数描述样本分布，均值区间不是分布区间，也不包含机制／数据近似造成的系统误差。
- 同时提供「暴击条件残差 DPS」：沿本次已发生的命中轨迹，用每击原生 CR/CD 计算条件暴击期望，再比较实际伤害。非普通伤害不重复加入暴击。该值不是整队解析期望；暴击触发机制可能改变后续轨迹，不得由此假定两种模式等价。
- 请求数严格分解为成功、失败、运行中取消、未开始、运行中。失败不计零伤害；出现失败立即停止其他线程。加载失败可能是没有开始任何 trial 的批次错误，错误单独保留。未完成批次的统计仅描述成功样本，不作为完整批次估计；预算截断可能产生完成时长选择偏差，显示的均值区间不消除这种偏差。
- 完成、失败、预算终止、主动取消和离开页面均终止 Worker。最多两个并发线程以限制真实 WASM 内存占用；未开付费算力。

## 本轮已验证证据

证据目录：`/workspace/GIDPS-cloud/real-batch-20261021`。

1. 缓存前／后同一实际 VV 轨迹的 1002 条计算（含完整解释）SHA-256 均为 `3030a1b128d8d5672af608b7f6125ce27decc9e47e6f0c841ddc84b6952bffdf`；公式耗时 15775.1→9362.0 ms。缓存仅用于单次 resolver 私有的、已完整校验并深度冻结的对象，公开可编辑重放不缓存；不跳过输入或来源校验。对应 `memo-profile.json`。
2. 满能，种子 12021…12024，真实 120 秒：1 线程 61.5871 秒，2 线程 37.6533 秒。所有 trial 的伤害、普通命中数、暴击数、条件期望、来源身份及完整事件哈希逐项相等。前两个种子的事件哈希与上一轮原始 VV 捕获一致。对应 `pilot-serial.json`、`pilot-parallel.json`、`audit.json`。
3. 受控测试 CR=0／1（测试覆盖值，不声称合法圣遗物）：190 次普通命中分别 0／190 次暴击；总伤害 379965.84771250427／641195.8883496803，条件期望在浮点精度内吻合。对应 `crit-zero.json`、`crit-full.json`。
4. 1000 次请求主动取消：0 成功、0 失败、2 运行中取消、998 未开始，所有 Worker 终止；浏览器测试检查终止数量，单元测试检查取消后迟到消息不产生更新。对应 `cancelled.json`。
5. 变更相关来源回归 109 项通过、0 失败（此前 102 项，新增 7 项），构建／类型检查通过。初轮浏览器三项通过；限时规模一项通过，真实错误／SPA 导航清理一项通过。追加半开窗、提前结束与不可逆暴击条件期望保护后，针对单元测试 10/10 通过。没有再次运行整个项目全回归，不能把历史 86 项失败写成已解决。

实测小样本线性估算：1000 次约 9413 秒（2.61 小时），10000 次约 94133 秒（26.15 小时）；含启动开销，非保证。真正完成的规模以 `scale-1000.json` 的 `counts` 与 `status` 为准，**请求 1000 不等于完成 1000**。本轮没有启动 10000 次无界作业。

实际限时结果：900000.5 ms，**103 成功、0 失败、2 运行中取消、895 未开始**；状态 `budget`，不是 1000 次完成。103 样本平均总伤害 483864.6120，平均 DPS **4032.2051**，样本标准差 140.8869，标准误 13.8820，p05／p50／p95 为 3803.9212／4059.2109／4250.3017；样本均值 95% 正态近似区间 4004.9964–4059.4138。条件暴击残差 DPS 均值 -11.8190，近似区间 -28.1577–4.5198，不能解释为整队模型准确率。

资源曲线 180 个采样点，容器总内存峰值 12662329344 bytes（含文件缓存），结束与导航清理后匿名内存 167104512 bytes。没有遗留批量 Worker。`remaining-jobs.json` 保存尚未完成的 **897** 个原始 trial index/seed；完成集合不是连续前缀（102 未完成、103 已完成），不能简单从第 103 项接着跑或重复全部 1000 项。继续时必须保留原配置和执行器身份、逐项补齐缺失编号、去重后重新归并；本轮没有启动续算。完整 1000／10000 的真实结果仍未交付，原因是实测计算成本，不是权限拒绝或连接异常。
