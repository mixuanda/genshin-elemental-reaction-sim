共享核心现在计算真正写入 Go 护盾的 HP，并记录生成、刷新、上一轮受击消耗的计算 ID。生命／攻击／防御／精通读取保留原位置与次数；辛焱爆发的防御保存值、蓝砚恢复时两次独立属性读取、托马叠盾与上限分别有来源记录。结晶盾分开解释等级基础 HP、碎片生成时精通快照及受击时护盾强效合计，随后接入同一受击吸收核心。两版结晶的 Frozen 元素处理差异、诺艾尔来源中的元素字段和原生触发顺序均保持原样，未把固定源码行为宣称为游戏真值。

结果页可选本次护盾公式记录，查看公式、变量、数值代入、中间值及来源，再送入永久独立计算器编辑和保存 JSON。HP、DEF、比例中间值按实际单位显示。编辑只重算所选表达式；不会假装重新执行后续护盾生命周期或整队轮转。旧结果没有生成 ID 时明确显示解释缺口，不能补造历史来源。
