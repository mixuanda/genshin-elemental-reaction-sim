# 固定来源共享状态与相位观察（119）

本批补齐跨角色共用的在途攻击、普通感电／燃烧、耐力和护盾回调的状态描述。来源相位分析现在能读取更多实际捕获值、原生时钟和任务关系；未知闭包继续构成明确缺口。独立单击／完整技能计算器及共享公式入口保留。本批没有新增角色动作合同，也没有宣称整体稳态或游戏机制验证完成。

## 实际实现

待执行攻击的快照生成和伤害应用任务记录实际 `AttackInfo`、快照属性、相对来源帧、碰撞范围、反应标记及回调槽位；没有描述的命中回调和自定义形状仍报缺口。历史快照与几何取副本。同一核心队列中共享 `AttackEvent` 的任务保留相对别名关系，不把两个数值相同的独立对象误作同一对象，也不导出内存地址。快照生成任务不比较即将被原生 `generateSnapshot` 覆盖的旧快照。

时间字段按源码实际用途保留：快照来源帧参与阿莫斯之弓／弹弓的飞行时间判定，攻击事件来源帧用于赛索斯的技能代次判断。快照年龄 = 当前帧 − 快照生成帧。本次柯莱在途攻击观察于第 280 帧，快照生成于第 247 帧，故记录年龄 280 − 247 = 33 帧；同时保留实际剩余 85 帧及一个未知命中回调，未把它标为完整闭包。

普通感电补充首次／递归 Tick、命中事件和附着量衰减任务的描述，保留核心时钟 70／60／6 帧延迟及真实订阅次序。燃烧补充敌人时钟上的 15 帧任务、捕获的代次与计数器，保留源码仅跳过 counter=9 的分支。观察函数不执行原回调，不修改附着量、队列或随机流；其他 Enemy 实现仍走原队列，并保留无法描述的缺口。

耐力与护盾强效添加描述符传递通道，接入风／岩共鸣、共用 Golden Majesty 武器函数、逆飞的流星、千岩牢固、染血的骑士道、坚骨及暗巷的酒与诗共 8 个注册点。普通 `*shield.Tmpl` 的共享伤害回调获得明确描述；其创建帧键和纯计算回执编号不再进入相位比较，当前生命值、元素、归属、到期时距及有序位置仍保留。自定义盾继续报告私有状态缺口。敌人生命值阈值掉球任务记录实际数量、元素和原生 100 帧投递延迟。

源码依据：[攻击状态](validation/source-phase-attack-state-audit-20260930.json)、[玩家与掉球状态](validation/source-phase-player-state-audit-20260930.json)、[反应任务](validation/source-phase-reaction-state-audit-20260930.json)。两个来源固定提交分别为 `b4ae769d7c1c1bce68fce5faf0b460c5b5b7f541`、`a7dc4bf4f5e18390035ca0333fb6eb1d5fac32bd`；不把两条来源线视为同一规则。
