# 固定来源共享动画与动作阶段状态（121）

## 本批实现

本批将动画帧回调及其捕获状态一起保存在 `FrameFunc` 中：`Run` 仍执行原帧规则，`Phase` 描述同一规则读取的动画表、普通攻击计数、攻击速度和偏移量。动作替换帧规则时，描述符随之替换，避免 phase 观察沿用旧动画状态。观察过程复制当前表格，不重新查询 Stat、不运行游戏回调，也不更改原有切片别名和帧计算。

默认 hitlag 暂停回调在共享执行路径绑定到实际角色，并记录 `frozenFrames > 0` 判定；自定义暂停回调仍保留为未知。动画描述符通过原生构造点采集，而不是从角色名推断：classic 读到 `NewAbilFunc` 459 个调用点、`NewAbilFuncWithOffset` 3 个、`NewAttackFunc` 110 个、`NewAttackFuncWithOffset` 2 个；Stellar 分别为 483、3、116、2 个。这些是构造器的源码调用点统计，不是逐角色验证数。Chasca 在两 lane 的状态读取时机不同，仍须遵循各自固定来源语义。

## 保留的未知项

任意自定义 `Frames` 与自定义 hitlag pause 回调不会被推测其闭包内容；`OnRemoved`、`UseNormalizedTime` 和排队动作回调也仍保持显式缺口。描述符只报告可审计的捕获与 actor 关系，不代表所有动画状态均完整，也不自动证明动画时序、hitlag 或整轮 phase 已闭合。此共享来源状态工作不改变独立计算器的产品入口与单技能计算路径。

## 实际捕获与前后比较

复用 119 批归档的芭芭拉／丽莎／柯莱／香菱场景，保持每条来源自己的配置、种子和观察政策。两场各实际执行至第 406 帧动作耗尽；虽然配置观察上限为 24 秒，但本场不是固定窗口 DPS 基准。配置显式忽略爆发能量，也不是能量验证。

每条来源记录 14 个观察边界、14 次伤害应用，总应用伤害为 13,294.693123088311。与修改前归档逐项比较，观察帧以及每次应用的帧、目标、原始／应用伤害、目标前后生命值和暴击标记完全一致；不据此声称所有来源情景都已验证。

每条来源实际得到 1 条普通攻击构造器记录、5 条技能构造器记录和 6 条默认卡肉暂停记录。这些是重复观察条目数，不是 12 种不同机制或角色。普通攻击捕获 `normalCounter=0`、`attackSpeed=0`、`offset=0`，并保留两条来源不同的原始帧表；默认暂停记录实际角色索引及 `character.frozenFrames > 0` 条件。

本场两类动画回调缺口消除，去重缺口由 66 降为 64，完整边界仍为 0。分析保持 `not-established`，稳态 DPS 为空；本场标记也不满足同输入位置的周期前提。Stellar 相位 JSON 导入／导出完全一致，两场实际使用的 WASM 哈希均匹配本批产物。[原始捕获](validation/source-shared-animation-browser-20260930.capture.json) · [浏览器结果](validation/source-shared-animation-browser-20260930.result.json)。

两种 WithOffset 构造器、非零攻速、角色覆盖回调的所有分支和独立断言的实际卡肉暂停正分支，本批没有新增运行样本；保留源码审阅和编译证据，不扩张结论。
