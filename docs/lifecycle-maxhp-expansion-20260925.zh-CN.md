## 动态生命上限

新增显式模式 `gcsim-b4ae769-ratio-preserving-v1`。已声明的队伍生命百分比、固定生命增益在应用、同键覆盖和到期时更新真实生命池：保留生命比例，按新上限换算绝对生命；这项调整不计为治疗、消耗或伤害。到期通过优先级 -1 的主队列任务处理，早于同帧动作、条件分支和周期治疗。后台角色也同步，未来到期任务进入检查点。

共享 AST 依次显示 `MaxHP = BaseHP × (1 + HP%) + FlatHP`、原生命比例、新生命值和绝对调整量的公式、变量、数值代入和中间结果。正常团队页提供开关，账本可以展开同一轨迹；完整 JSON 保存实际属性、变化来源、事件顺序、生命链和末态。独立结果校验从已接受动作及其增益重建上限，不以捕获值自证。

生命之契保持绝对值，不随上限变化缩放或提前钳制。零治疗／生命消耗不改变债务；后续非零债务操作才按新上限处理。固定源码的同口治疗余量仍有 TODO，人物专属 `OnHPDebt` 同步改属性及死亡复活未映射。模式保持 `fixed-source-assumed`，不升级为游戏 verified。[来源审计](cross-validation/player-max-hp-source-audit.md)。

实测叠加／覆盖／到期例：上限 `10000 → 20000 → 25000 → 20000 → 15000 → 10000`；初始生命 5000，在 25000 上限时以 25000 治疗先抵消 20000 债务、实际回血 5000，最终生命 7000，上限调整累计 -3000。另一后台角色保持原 40% 比例和绝对债务。到期同帧条件与周期治疗读取已恢复的 10000 上限。

## 星旋跳跃与下落

星漩涡爆炸生成的全局资格现在由真实被接受的 `jump` 消费，产生独立腾空状态；随后真实 `plunge` 结束腾空，下落伤害进入普通伤害核心和同次计算器回放。合法编译器使用实际前缀执行反馈，不能从普通跳跃文本推定星旋资格。空中非下落动作与重复下落被拒绝。

资格在授予后 300 帧边界失效，已腾空状态不会因资格到期自行落地；同帧动作不会提前消费较后相位的爆炸。结果校验器根据同次实际星漩涡投递及已接受跳跃重建资格，修复了旧校验器仅接受声明腾空来源的限制。

`guide-profile-source-conflict` 保留：三／六次触发与 180 帧指南模型没有因此解决固定源码计数、181 帧及实体类型分歧。跳跃途中遇爆炸的升级、高度及武器动作帧自动推导尚未实现。固定原文 11 文件（含 LICENSE）已持久归档，22,721 字节，[来源审计](research/stellar-swirl-high-jump-source-audit.md)。

实测跨角色消费：186 帧自然爆炸，187 帧另一角色跳跃，196 帧一击物理下落；下落仅计入普通伤害一次，完整 JSON 恢复后计算器伤害相等。
