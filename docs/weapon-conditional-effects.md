# 武器条件快照公式：19把新增范围

本增量新增 `packages/game-data/src/weapon-conditional-effects.ts`，与已存在的16把静态武器和12把转换/叠层武器不重复。这里的“支持”指可确认数值条款在**显式命中前上下文**中的执行，不表示整件武器全部机制、自动触发或循环覆盖率已经完成。19把均保留 `provisional` 状态；来源、输入、AST和局限随结果返回。

数据模块只生成共享 `FormulaExpression`，包括倍率、条件、负值和实际输入；不在UI预先加减面板。普通增伤带攻击标签过滤，面板属性进入 `pre-panel` 阶段，随后由共享核心计算与记录执行轨迹。

## 条件与时序边界

- 所有启用规则缺少必要字段时，都返回非空 `missingConditions` 和具体 `effectBlockers`，不能把未知状态当作false/零层。明确停用则不要求条件。
- 钢轮弓源码要求前台普攻/重击命中，18帧触发间隔，360帧整体刷新。弹弓阈值为18帧，恰好边界包含；输入秒数不用于推算距离或弹速。
- 黑岩源码要求击杀归属装备者且触发时在前台；三层分别1800帧，到达上限后环形刷新单层期限。这里仅恢复仍有效层数。
- 宗室源码针对自身非零伤害；非暴击在18帧间隔外加层，暴击即清层（不受该间隔限制），零伤害不改变层数。当前命中的增伤/暴击结算使用**命中前**层数，不能把当前事件新层数倒算进伤害。
- 盈满之实允许后台归属反应触发；18帧内忽略的反应不会刷新360帧衰减期限，达到上限但被接受的触发会刷新。当前模块不生成这些事件。
- 遗祀玉珑离场300帧后获得增益，上场600帧后清除，换人会使旧任务失效。已经生效的增益不会因短暂离场立即清除，故 `offField` 不能替代 `weaponEffectActive`。目录“超过5秒”和固定源码300帧的触发边界尚未游戏内验证。
- 铁影阔剑目录使用严格“低于”，固定源码的排除条件是`hp > threshold`（即生效含等号）。精确等号不选边；高于/低于阈值的数值分支才执行。
- 弹弓按每个命中的箭矢类型与旅行时长恢复；混合技能中的不同命中不能共享一个未经确认的箭矢状态。附着条件同样是当前目标的状态，未提供多目标自动状态切换。

## 固定来源与防漂移

目录正文通过 `equipmentDescriptionSource` 取得活动版本的不可变URL，目前对应7.1目录；代码逐个命名规则精确校验中文条款，且独立保存经固定源码核对的R1–R5字段表。目录的文本或任何精炼数值变化都会要求重新核验，不会通过泛化文字解析自动启用机制。

参考实现固定为 [gcsim b4ae769](https://github.com/genshinsim/gcsim/tree/b4ae769d7c1c1bce68fce5faf0b460c5b5b7f541)，其中使用的21个Go文件原字节和MIT LICENSE（共22文件、23,828字节）保存在 `packages/game-data/sources/weapon-conditional-effects/`。`manifest.json`逐文件记录不可变页面URL、raw URL、SHA-256、字节数和获取时间；模块导出 `weaponConditionalSourceEvidence`。黑岩/宗室同时记录五种武器包装器与共享实现，防止只核对一把后无证据推广全系列。原[MIT许可证](https://github.com/genshinsim/gcsim/blob/b4ae769d7c1c1bce68fce5faf0b460c5b5b7f541/LICENSE)及版权声明一并保留。

这是社区数据与开源参考实现的交叉核对，不替代官方内部机制或全部游戏内测量。明确未执行的移速、攻速、抗打断、自动层数变化、触发窗口、随机暴击反馈不计作完整武器覆盖。
