# 原生相位捕获、状态归一化与实际周期正例

2026-09-28。本批已在实际星辉来源运行中建立一个有伤害的重复周期；经典版同一输入因脚本可读取的计数持续变化而正确保持“未建立”。这是固定源码执行域内的条件结果，**不是游戏内验证，也不代表全量 goal 完成**。

## 本批实际改动

- 077／080 按真实读取语义归一化过期状态、空冷却队列、失效附魔、耐力恢复时距和纯存储用的装置空位；保留仍可被技能或脚本读取的时间与计数。依据见[逐字段矩阵](validation/phase-state-normalization-matrix-20260928.md)和[目标状态说明](source-phase-target-normalization-20260928.zh-CN.md)。
- 078 建立事件与任务的来源描述符，导出真实闭包捕获值、启用状态、有序订阅、剩余时限和 FIFO。观察过程不执行原回调；未知回调继续报告具体缺口。
- 079 读取角色、武器和圣遗物保留对象的私有状态，共享角色引用带实际角色索引。未审查数值的时钟语义、函数和不支持的图仍有缺口。只对经过源码审查的字段或分支消除缺口，包括温迪六个私有字段全部为零的休眠分支；非零时回到未闭合判定。详见[私有状态审计](research/native-phase-private-state-source-audit-20260928.md)。
- 081／083 将纯统计观察与会调用属性、护盾回调的统计订阅区分。后者仍进入状态比较并引用顶层状态，避免把会影响战斗的回调误作纯日志。桥接月绽放／StellarConduct 回执属于单独审查的纯观察订阅。
- 082／085 为 modifier 提供只读捕获描述，接入 9 个共鸣／Ascendant Gleam、5 个通用武器以及安柏 A1／A4 的实际捕获值。捕获向量取副本，动态层数和 buff 取当前值；不调用 Amount 来猜状态。这些描述不等于所有相关角色和武器已闭合。
- 084／086 接入普通攻击回能概率及 ICD、共鸣、粒子投递、Ascendant Gleam、冷却 worker 等共享回调。已完成冷却的残留 worker 指针不再误报为待执行闭包；真正待执行的 worker 记录动作、角色与当前 worker 身份关系。
- 087 为星辉版共享模板的起跳订阅记录角色与实际跳跃状态。该补丁只属于星辉版。
- 修复 `Flags.Custom` 的快照别名：每个历史相位现在保存字典副本，后续运行不能倒写旧记录。
- 新回执的 `damageSincePreviousBoundary` 按上个边界之后的实际敌人伤害应用逐项求和。周期比较直接累加这些区间值，避免两个增长的累计浮点数相减产生尾差；状态、时长和区间伤害仍精确比较，没有放宽误差阈值。旧回执仍可导入，继续使用原累计差值语义。
- 公开来源队伍页提供随机循环和确定性伤害循环两个可编辑示例，展示逐区间实际伤害、周期 DPS 的公式与数值代入，并保留完整 JSON 导入／导出。独立单击／单技能计算器继续是原有一等入口。

## 实际测量

[完整命令与产物身份](validation/phase-captures-measurements-20260928.json)、[最终页面记录](validation/phase-captures-browser-20260928.result.json)。

| 场景 | 原生边界／实际命中 | 最后边界缺口 | 实际结论 |
|---|---:|---:|---|
| classic：温迪 C0 E、冲刺、等待，40 秒 | 6／6 | 0 | 未建立周期。`tags.skill_charge` 随冷却完成递增，原生脚本能读取它，因此保留该差异。 |
| stellar：同一可编辑输入，40 秒 | 6／6 | 0 | 周期 1 轮、444 帧；末尾比较边界为 1333、1777、2221。 |
| classic：安柏西风普攻随机循环，16 秒 | 9／9 | 2 | 未建立。西风回调与武器私有字段仍有缺口，且真实 RNG／回能概率等状态变化。 |

星辉正例每周期实际伤害为 **2059.5758212353603**，所以条件 DPS = 2059.5758212353603 × 60 ÷ 444 = **278.3210569236973**。没有在边界重置角色、敌人、能量或随机数发生器。固定来源温迪 E 自身设置 `HitWeakPoint=true` 并产生固定数量粒子，本示例使用这段原生行为；不能据此声称游戏里的温迪 E 必定暴击。经典／星辉两场均完成相位政策及全部观察的 JSON 恢复，页面异常为 `[]`。

首次页面检查真实失败：[原始回执](validation/phase-captures-browser-initial-20260928.result.json)。它揭露冷却残留指针误报、星辉共享起跳回调未描述，以及累计差值约 10^-12 的尾差；随后进行了上述针对性修复。同时修正了“经典版应成立”的测试预期，因为可查询的 `skill_charge` 是真实状态，不能删除它以制造正例。
