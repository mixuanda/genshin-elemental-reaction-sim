# 固定来源私有数值状态与有限来源读取（125）

## 本批实现

本批将角色私有数值按源码语义分类后纳入共享 phase 状态读取：统计属性向量递归复制并保留各自字段身份；已审阅计数器保留原始值；已确认的绝对帧期限转换成相对当前帧的剩余值，并保留其严格／包含端点条件。无法确认语义的字段继续列为缺口，不把数字一概当作计时器。技能实例 token `skillInitF` 用于判别旧技能任务，不可脱离捕获的代际身份单独归一化。

本批登记了三项来源规则：提纳里 E 的直接攻击、爱可菲 Q 的角色任务延迟攻击生产（实际延迟 92 帧）及欧洛伦 E。爱可菲 Q 是角色任务生产者，不是直接攻击规则；久岐忍 Q 已在之前登记，本批没有新增。AST 读取映射使用已有 `actionCapabilities` 元数据识别转发／异元素旅行者接收者，本批没有新增 AST 提取器，也没有因此填补全部天赋读取缺口。

## 字段审计与运行结果

完整字段、规则、来源行及排除原因见[私有数值审计](validation/source-private-numeric-audit-20260930.json)。按直接声明在原生 `char` 结构体的数值字段口径：Classic 审阅 420 个字段，其中统计向量 81、计数器 112、绝对期限 9、既有例外 1，其余 217 保持未知缺口；Stellar 审阅 461 个字段，其中统计向量 92、计数器 117、绝对期限 9、既有例外 1，其余 242 保持缺口。上述字段计数来自固定来源 AST 与逐字段源码引用审计，不等同于所有私有类型、嵌入接收者或角色机制覆盖。

历史 122 捕获在 Classic 与 Stellar 各有 33 个唯一 phase 缺口。本批最终状态每 lane 减少至 3 个唯一缺口：Lisa 与 Barbara 各一个事件回调，以及 Barbara 的 `skillInitF` 代际 token；六个 phase 观察边界仍全部不完整。每 lane 新执行一次 175 帧聚焦场景，观察到同一伤害（45.39786424509601）；来源应用、action logs、phase 帧及 player state 均与对应 lane 的历史捕获一致。Classic 与 Stellar 的相位标记本身不同（54 帧／27 帧），按各自固定来源保留。全部 native 运行共 4 次：修正遗漏 Lisa 计数器语义前后各一次双 lane 捕获；最终对照复用了历史 122 捕获，没有新增 baseline 模拟。

## 构建与界面检查

修正 Lisa `previousDischargeCount` 策略后重新执行了必要最终检查：Classic 来源构建 5.740 秒，Stellar 6.095 秒；最终 Web 构建（包含 typecheck）3.727 秒；定向浏览器案例 3.911 秒。此前的 registry 0.109 秒、typecheck 2.920 秒、Web build 1.161 秒和浏览器 3.835 秒为修正前结果，最终结论以修正后的构建、捕获与检查为准。最终页面无错误。本批没有运行全量单元测试或性能矩阵。

三条新增来源规则（提纳里 E、爱可菲 Q、欧洛伦 E）只有源码审阅与两 lane 构建证据，没有本批角色运行样本。新增后的来源动作清点为 Classic 234、Stellar 248 个 E/Q 绑定，尚分别剩余 135／149 个绑定（123／135 个不同来源方法）。来源包计数既不是完整角色目录，也不是游戏验证或全分支覆盖；此前“角色注册数”不得解读为目录完整度。
