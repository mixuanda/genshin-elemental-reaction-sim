# 随机启动诊断：配对差值与小样本统计

核查日期：2026-09-23。本记录只规定统计解释及实现建议；没有运行仿真、统计程序、测试或构建，没有据此验证随机稳态。

## 观测单位与估计对象

预先固定窗口和种子数（默认 `n=8`，最多 `32`）。每个种子分别初始化零能量与满能量场景，各自连续运行足够长的时间；初始能量之外的场景参数保持一致。在同一次连续轨迹上提取 `W`、`2W` 窗口，不在窗口边界重置状态或随机流。

设第 `i` 对种子在窗口 `T` 的 DPS 为 `F_i(T)`、`Z_i(T)`，定义有符号差值 `d_i(T)=F_i(T)-Z_i(T)`。正值表示该窗口内满能量启动 DPS 更高。要估计的是指定窗口、配置与随机模型下的期望差，而不是无限时间稳态 DPS。这里的一次样本是一对种子运行，样本数是 `n`，不是 `2n`。NIST 的配对方法是先逐对相减，再对差值做单样本分析。[NIST：配对观测](https://www.itl.nist.gov/div898/handbook/prc/section3/prc311.htm)

若 `W` 指 `[0,W)`，`2W` 指 `[0,2W)`，两个窗口重叠且相关。比较启动差是否随时长变化，应先形成每种子的 `c_i=d_i(2W)-d_i(W)`，再跨种子分析 `c_i`；不能把两组当作独立样本。也可预先指定等长的不重叠窗口 `[0,W)` 与 `[W,2W)`，但它们仍共享轨迹状态，仍须先作种子内差值。这些是本项目采样设计的推导，不是 NIST 对本模拟器的验证。

## 均值、样本标准差与均值置信区间

对某个固定窗口的 `n≥2` 个完整配对差值：

```text
d̄ = Σ d_i / n
s_d² = Σ (d_i − d̄)² / (n − 1)
s_d = √s_d²
SE(d̄) = s_d / √n
df = n − 1
CI95 = [d̄ − t_(0.975,df) × SE(d̄), d̄ + t_(0.975,df) × SE(d̄)]
```

`s_d` 描述逐种子差值的离散程度；`SE` 描述均值估计的抽样误差尺度。不能用 `s_d` 代替 `SE`，也不能把满能量、零能量各自的 SD 直接相减得到差值 SD。建议界面名称为“配对均值差的 95% t 置信区间”，同时显示 `n`、`df`、`s_d`、`SE`、临界值和差值方向。[NIST：配对统计量](https://www.itl.nist.gov/div898/handbook/prc/section3/prc311.htm)、[NIST：均值置信区间](https://www.itl.nist.gov/div898/handbook/eda/section3/eda352.htm)

精确的小样本 t 覆盖率要求不同种子对之间独立、同分布，且**差值**服从正态分布；不要求两种启动场景在同一种子内独立。本模拟器的离散触发、缺能跳过爆发等可造成偏斜、多峰或大量零差值，因此 `n=8` 时应将该区间视为依赖近似正态假设的诊断；`n=32` 也不能自动消除此限制。NIST 明确指出，小样本或严重偏斜时，该区间对非正态性的稳健性有限。[NIST Dataplot：置信区间假设](https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/conflimi.htm)

95% 指同一方法在重复采样中的覆盖率，不是当前区间有 95% 概率包含固定真均值，也不是 95% 单次运行会落入该区间。[NIST：置信水平解释](https://www.itl.nist.gov/div898/handbook/eda/section3/eda352.htm)

## 经验 p05 / p50 / p95

建议固定并记录 Hyndman–Fan type 7 线性插值。将所报告变量的样本排序为零基数组 `x[0..n−1]`，对 `p∈{0.05,0.50,0.95}`：

```text
h = (n − 1) p
j = floor(h)
g = h − j
Q(p) = (1 − g) x[j] + g x[min(j+1,n−1)]
```

NIST 列出多种常用分位数规则，尤其小样本结果会不同；type 7 是一种可复现选择，不应声称它是唯一正确规则。[NIST：百分位数](https://www.itl.nist.gov/div898/handbook/prc/section2/prc262.htm)

这些分位数描述**逐种子样本值**，不是均值的置信区间，也不是带置信保证的总体容许区间。`p05–p95` 对应名义中央 90% 的分位范围，不能标为“95% 区间”。明确每组分位数来自 `F_i`、`Z_i` 还是 `d_i`。`n=8` 时，type 7 的 p05/p95 分别只在最低两点、最高两点之间插值，不能将其解释为已可靠测量极端尾部风险；保留逐种子原始值更便于审计。

## 同种子与随机抽样步调不同

下面是配对差值的方差恒等式及其在此设计中的推论：

```text
Var(F − Z) = Var(F) + Var(Z) − 2 Cov(F,Z)
```

同种子可形成共同随机数耦合；只有产生正协方差时才会减少差值方差。零能量和满能量场景可能执行不同动作、产生不同命中次数，从而使条件抽样和 PRNG draw index 失去事件对应。相同种子并不保证“相同命中使用相同随机数”，也不保证方差缩小。

只要各场景的边际模拟仍正确、不同种子对独立，抽样步调不同不会使跨种子的配对均值差目标失效。它限制的是逐事件随机结果对齐解释。应保存种子、随机模型版本、子流命名及抽样日志，标注“同种子配对，事件抽样可能不同步”。已有独立子流应保持真实身份；未经实现，不可宣称按攻击事件对齐。窗口提取也不应重置或回放随机流。

## 必须保留的边界说明

- `n=0` 没有统计量；`n=1` 可以显示唯一观测和描述性分位数，但样本 SD、SE、t 区间应为空并说明样本不足。不可将未定义 SD 设为零。
- `s_d=0` 时公式给出零宽区间；应标注“当前样本未观察到差值变化”。有限随机样本的零方差不能证明过程确定或已进入稳态。
- 完整配对、有限数值与不同种子是前提。缺少一侧运行时应显式报告失败；不可将缺失值补零，或悄悄删去失败种子。不同种子仅是独立伪随机重复的设计假设，应记录实际派生方式。
- 同时展示 W 和 2W 的区间时，各区间是边际 95%，不是联合 95%。不可把重叠窗口当作额外独立重复，也不可挑选“最好看”的一个窗口作整体结论。
- 普通固定样本量 t 区间不授权根据当前区间是否变窄、包含零或排除零来提前停止。预先固定 `n`；若要自适应停止，需要另行定义具有相应覆盖保证的方法。
- 区间包含零不证明等效；区间很宽时只是证据不足。即使预先设定实际差异容忍度，有限时窗的启动差诊断也不证明状态分布平稳或长期收敛。本功能不应从 p 值或此区间生成“已验证稳态”结论。

最后几条为本项目对常规固定样本推断的解释约束，不是新的稳态判据。
