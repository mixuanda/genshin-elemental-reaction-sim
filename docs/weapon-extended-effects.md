# 剑与双手剑：额外条件公式及来源边界

本批新增 `weapon-extended-effects.ts`，登记 **43 把武器的可执行数值条款**。数量表示至少一个有固定参考实现的属性或普通增伤条款，不表示武器的所有被动、事件时序或团队传播均已完成。所有规则仍为 `provisional`。本批不覆盖此前已登记的 80 把，也不重复 Skyward Blade 等旧模块的部分条款。

输入明确恢复某次属性取样/命中时的合法状态；输出共享核心的公式 AST、变量值、变量定义、来源和适用标签。面板百分比、真实固定攻击 buff、普通伤害增伤分开表达。腐殖、狼牙等限定技能的暴击率，裁叶与赤角的命中前附加伤害，都没有错误放入全局暴击率或 `flatAtk`。

生产 dispatcher、控件委托、严格 schema 和集成检查由父任务接入；本独立模块任务没有运行项目测试、构建或数据生成命令。

## 已发现并保留的来源差异

1. **星锋剑（ExaiphanesBlade）整把被动排除**：目录R4/R5命中窗口ATK32%/40%，固定GO为28%/32%；GO还将R2–R5的常驻共鸣暴伤错误绑在命中窗口。未使用低精炼相合掩盖高精炼冲突。
2. **熔猎异端之刃（HereticsMoltenBlade）排除**：GO仅提供0–18手动档位，没有上一秒移动距离到实际ATK的映射。没有把人造档位标为完整移动机制。
3. **金律铸影（ForgedByTheGoldenMelody）排除**：需独立当前乐章与复调状态，并有星烁专属乘区；GO复调展示10秒与目录12秒冲突。
4. **聊聊棒排除**：固定gcsim为`NewNoEffect`且TODO，注释不能充当独立执行交叉核对。
5. **救赎之斩部分保留**：EM表达式相符，ATK表达式却读`condReact`而非`condStellar`。模块仅执行EM，返回ATK条件冲突阻碍。
6. **黑蚀部分保留**：gcsim明确注明触发爆发漏吃新ATK。输入只恢复已确立窗口，不能宣称触发击完成。魔导使用现有`witchLessonsCompleted`，其本条标签明确要求已确认队伍魔导条件。
7. **狼的武功歌部分保留**：固定源码叠层缺少owner/普攻筛选与0.01秒间隔；CD检查装备者`IsHexerei`而非目录的队伍魔导。只执行来源数值一致、人工确认合法层数的普通增伤。
8. **海渊快照差异**：GC累计实际清除债量，GO用当前HP的25%简化；这里要求独立`clearedBondOfLife`，不拿当前HP替代历史清除值。

## API、上下文和验收交接

导出 `SUPPORTED_WEAPON_EXTENDED_IDS`、`hasWeaponExtendedRule`、`getWeaponExtendedControls`、`resolveWeaponExtendedEffects`、`weaponExtendedExcludedRules`。结果始终含`missingConditions`数组。必要条件缺失同时进入阻碍与missingConditions，由上层拒绝误作完整配装。明确失效的独立窗口无需其无关快照。例如海渊清契窗口为false时不要求清除量；岩峰团队窗口为false时不要求触发防御。

新增字段为 `secondaryWeaponStacks`、`weaponExtraEffectActive`、`energyZero`、`wearerEnergyMax`、`nightsoulBlessingActive`、`weaponSnapshotDef`、`clearedBondOfLife`；复用已协调的`moonsignLevel`、`witchLessonsCompleted`和`platformPassiveActive`。雾切与降临从`args.characterId`查活动角色目录，不提供任意身份复选框。

`reviewed-expectations.json`有43把手列端点案例，以及30个独立条件边界记录。一心／降临只列合法R1，其余R1/R5；包括伤害标签不适用、雾切角色元素、织月40/60边界、海渊两个窗口、岩峰不同持续时间、零能量、月兆和护盾分支。期望值没有通过生产resolver生成。本任务未执行这些案例；父任务选择必要集成路径，运行唯一新增focused测试并报告实际结果。
