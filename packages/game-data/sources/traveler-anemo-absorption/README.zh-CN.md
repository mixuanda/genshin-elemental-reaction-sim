# 风旅行者 Q 实际吸收与 C6 条件分支

本证据扩展现有两性 `traveler-cross-*-anemo-burst-c0` 入口。存储 ID、旧无吸收 C0 数值和原来源归档不变；`c0` 是历史 ID，并不再表示当前实现只覆盖 C0。实现仍为固定来源的 provisional 条件重建，不是游戏实测认证，也不是自动团队轮转。

`manifest.json` 绑定原 `traveler-cross-source-casts/source.json.gz` 的 SHA256，以及实际读取的原始源码 SHA256/Git blob。未修改原 gzip、manifest、definitions 或 Golden；没有复制 Go 代码。数值采用固定 Optimizer `180a0a1015cb725c7570cd828eb086749960df98` 两性实际 `char.skillParam.TravelerAnemoM/F.burst[1]` 全15级向量，男性独立表再核对；行为采用固定 gcsim `a7dc4bf4f5e18390035ca0333fb6eb1d5fac32bd`。原 Go 的全部15级冲突向量另保留，T10 的 `.3384` 不覆盖本实现数值权威 `.4464`。

- `burst.go` 在起手分别 `Snapshot(&ai)`、`Snapshot(&aiAbs)`，冻结整套属性；之后只给 `aiAbs.Element` 赋成功吸收元素，不在吸收时重拍面板。因此风伤和吸收伤害必须各自使用起手时对应元素的增伤。完整分支用不同快照 ID，吸收的 ID 还包含元素，不能因换元素继续借旧最终增伤。
- 检查帧为 `39+18n, n=0..17`，首次成功后停止递归。Q 的机会为 `94+30i, i=0..8`，先风本体，再同帧吸收附加；晚吸收不补先前伤害。345f 成功时末击334f已过，附加数为0。无吸收末尾363f空任务不会被强加到已经成功吸收的分支；实际观察还须覆盖该性别来源状态寿命（男336／女334f）及实际吸收检查。
- `enemy/attack.go` 先算伤害，再 `Tasks.Add(0)` 执行回调。任务堆同帧依创建顺序运行；两项伤害计算都早于各自 `c6cb`。`cons.go` 的回调只对实际命中的敌人，按该击元素施加20%减抗600f；同键刷新，不叠层。目标抗性在伤害时读取，并非进攻快照的一部分。首对两击不能使用本对事后新挂的减抗。
- 完整 C6 当前只证明“起手时目标没有此前本旅行者对应元素 C6 减抗”的分支。后续资格由各元素更早的真实接触独立推导，落空不挂减抗。已有旧减抗或未知初始状态只能计算实际单击，单击明确本击前的真实状态，不猜剩余时间。已含减抗份额用于补差。
- C1 不新增这次 Q 直接伤害；C2 的永久 ER 不改本击伤害；C3 的 Q+3 已由有效 Q 等级一次提供；C4/C5 属于 E。C6 按上述实际目标状态处理。没有新增 E、普攻、治疗、能量或反应实体。

敌人抗性是用户声明用于本次各元素的共同输入，不是敌人库推断。若目标风与吸收元素抗性不同，请按对应元素单击分别填写。历史快照只冻结进攻面板，不代表历史敌人抗性。没有推断几何接触、附着、ICD或自动反应；附加段范围与风本体不同，完整模式分别记录每个机会的实际命中或落空。
