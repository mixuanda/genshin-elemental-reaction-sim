# 水主长按E：充盈公式裁决与实际观察协议

本包新增 `traveler-hydro-resolved-aether-hold-c0`、`traveler-hydro-resolved-lumine-hold-c0`，各有露滴、结束激流、灵息之刺三个倍率模板。完整性指 C0 一次已完整观察的自身直接伤害，不指自动动作模拟、自动扣血时钟或团队轮转。旧无充盈分支保持独立。

## 已裁决与未裁决

数值权威是 [Optimizer 180a0a1](https://github.com/frzyc/genshin-optimizer/blob/180a0a1015cb725c7570cd828eb086749960df98/libs/gi/sheets/src/Characters/TravelerHydroF/hydro.tsx) 与固定游戏数据原文。`suffusion_hpCost` 明确用 `input.total.hp`；原始中文战技参数5也明确生命值上限。每次实际充盈消耗为该事件时生命上限的4%，资格严格高于50%。露滴的额外基伤为本击实际合格时生命上限×参数6；其条件独立于扣血回调。A4在突破4后为此次施放充盈消耗总和×45%，上限5000，只属于结束喷发激流。

保留的 [gcsim a7dc4bf 原文](https://github.com/genshinsim/gcsim/blob/a7dc4bf4f5e18390035ca0333fb6eb1d5fac32bd/internal/characters/traveler/common/hydro/skill.go) 存在三处冲突：扣血采用 CurrentHP；结束激流在起手调用时已读取并清空A4，后续才执行露滴扣血；露滴FlatDmg只在扣血ICD成功时赋值。新协议不采纳这三项，也没有修改原文或扩大倍率容差。

[KQM 一手测试记录](https://github.com/KQM-git/TCL/blob/3b228d151a7f9d1daeb7b6f10e4f780ec1089b51/docs/evidence/characters/hydro/traveler-hydro.md) 记录满长按22滴、最后露滴与结束激流同时发射，并记录长按E为动态取样。该固定记录及其视频链接已归档；本次没有重新播放、逐帧量测原视频。因此它**没有**证明首个耗血帧、精确耗血周期、同帧生命读取与扣血顺序。旧gcsim默认把最后一次露滴回调放在激流之后，也不能据此宣称真实游戏的最后扣血不属于本次A4。

这些缺口不是「所有来源缺失」。公式、等级向量和本次消耗归属已具备独立证据；自动事件时序仍待定向实测或可信独立实现。本协议要求实际观察的事件顺序，使现有证据可以参与正常完整伤害计算，不用假定时钟抹平冲突。

## 正常输入与单击独立性

完整日程填写全部伤害机会、实际接触／落空、结束帧与同帧顺序，以及生命事件账本。起点当前生命和MaxHP必须明确；`suffusion`事件由编译器按实际MaxHP扣4%，外部治疗、受伤或动态MaxHP变化使用 `observed-hp-state` 记录实际后态，并附说明。后者不计入A4。

每个露滴填写实际生命资格读取帧与顺序；编译器从前面的生命账本读取HP，不使用事件缓存值。结束激流只累计严格早于结束点的本次充盈消耗。所有伤害事件的实际进攻取样和所选目标独立记录，不假定发射等于到达。完整日程恰有已声明的1至22个露滴、一次激流及明确是否触发的一次灵息之刺；未确认完整记录、缺接触或缺历史面板均阻塞。

独立单击直接填写 `independentEvent` 的来源角色与本击实际状态。露滴只需本击实际当前HP/MaxHP；A4激流只需截至本次结束的实际充盈消耗；灵息之刺无需HP账本。不会索取未来露滴、未选命中的状态、完整目标历史或队伍轮转。

所有伤害公式使用共同AST。充盈阈值、HP加算、A4上限和减去面板已含份额均由该树求值与展示；不是仅写说明的附加倍率。每击 `includedSourceFlatDamage` 区分面板已有份额。历史快照每次准备均以明确输入为权威；转换身份绑定本击事件、HP、等级和已含份额，变化后旧物化结果明确阻塞。单击投影保留已发生事件，无需未来账本。

## 独立算例（条件观察，不冒充固定游戏帧表）

假设ATK2000、MaxHP20000、初始当前HP12000，E1，突破6，双方90级，抗性0.1，暴击率0.5、暴伤1，无其他增伤或反应。观察到54帧顺序0一次充盈消耗，顺序1读取露滴资格，顺序2结束长按；露滴与激流均在54帧发射，分别60/57帧交付。两击明确命中，无灵息之刺，已含来源加算为0。

- 消耗800，当前HP11200仍高于一半；露滴基伤 `2000×0.328 + 20000×0.0064 = 784`。
- 本次A4为 `min(5000,800×0.45)=360`；激流基伤 `2000×1.8928+360=4145.6`。
- 期望合计 `(784+4145.6)×0.5×0.9×1.5=3327.48`。
- 独立选结束激流，只输入本次消耗800和本击面板，期望值2798.28，不需任何未来或完整日程。
