# 兹白：真实观察资源账本的来源规则

本目录为 `observed-zibai-resources-v1` 提供规则常量与来源引用。核心可以直接读取 `definitions.json.constants` 和 `definitions.json.sourceRefs`。范围是 C0 一次月转时隙姿态的真实观察记录，或截至指定灵驹飞踏消费的观察前缀；不自动生成轮转、资源事件、命中或姿态帧序。

## 固定来源与规则

固定来源为 `frzyc/genshin-optimizer@180a0a1015cb725c7570cd828eb086749960df98`。此次补入完整英文 `tooltips_gen.json`，其中键 `11260001` 才保存月转时隙的详细资源规则；原 `char_Zibai_gen.json` 的技能说明只链接该键。另归档原有兹白 sheet、英文角色文本、skillParam 和该仓库 LICENSE，全部保留原字节。

规则为：资源上限100；合法灵驹飞踏要求至少70并消费70；基础姿态15秒；姿态内自然获取每秒10；普攻实际命中获取5，该途径间隔0.5秒；满辉条件下，附近队伍成员触发月结晶时获取35，该途径间隔4秒。灵驹飞踏的有效释放会重置**月结晶获点途径**的冷却，不等于重置普通攻击获点冷却，也不要求本次灵驹飞踏命中敌人。失败的施放尝试不算有效释放。C0在释放四次灵驹飞踏或持续时间结束后退出姿态。

`requiredMoonsign=2` 对应原文的 Ascendant Gleam（满辉）：tooltip给出该命名条件，固定角色sheet对同名N4追加伤害条件使用 `tally.moonsign >= 2`。这不是声称sheet实现了月结晶获点回调；它仅有静态伤害与条件公式。

Q在**实际施放时仍处于姿态**才为当前姿态追加1.7秒。原文没有给出每姿态只能延长一次的限制，不把总持续时间固定为16.7秒。资源常量的逐字段JSON路径和原文件行号见manifest。`framesPerSecond=60` 是本应用账本的时间换算单位，不是来源已经证明的首tick相位或动画时序。

## 帧序来自实际观察

所有事件帧和同帧顺序均由真实观察提供。首个自然获点tick的相位未知，不固定生成起手0帧、60帧或任何其他首tick。天赋文字没有证明自然获点、普攻命中、月结晶触发、消费、冷却重置、Q延长与退出之间的同帧先后，也没有证明冷却或持续时间边界帧的包含性。不得用事件类型排序代替观察顺序。

普攻获点证据是合格普通攻击实际命中，不是按键、重击或候选次数；月结晶获点证据是合格的实际反应触发，不能仅凭某击被归类为月结晶伤害自动产生35点。资源达到上限、合法消费前余额和使用次数都按观察账本的顺序核对。

原文能证明第四次有效释放触发退出条件，但不能确定退出相对于这次起手、两段伤害或其他同帧回调的精确时点。**完整生命周期必须有显式观察到的退出事件**，不能用四次计数或15秒算术伪造已验证的退出帧。

单次查询仅截取到所选灵驹飞踏合法消费结束为止的有序前缀：使用消费前及同帧更早的实际观察记录建立资格，并包含本次消费。后续资源、攻击、第四次退出和完整生命周期不是已经发生的单次消费的必要输入，不追索未来。

## KQM 的证据边界

[KQM角色页](https://library.keqingmains.com/characters/geo/zibai)与固定tooltip的文字规则一致；它仍注明角色研究结论尚未收录，Frames部分没有帧数据。[Evidence Vault](https://library.keqingmains.com/evidence/characters/geo/zibai)的机制栏目为空。这里仅记录2026-09-25读取到的语义交叉说明；没有把动态页面冒充固定提交、保存原始页面字节或为其声明内容hash。KQM不是本包首tick、精确边界或同帧顺序的证据。

## 原文身份与归档

`source.json.gz` 保存5份原始UTF-8文件字符串及独立的选中Git树条目。UTF-8重编码可还原原字节；每文件的字节数、SHA-256与Git blob SHA-1均在manifest中。全部文件与固定提交的完整、未截断树匹配。

完整tooltip为38604字节，Git blob为 `188d09480020761be49244617e3025b4cc845282`，SHA-256为 `f20816bb19c79a617a173d8bade6b7301810d92a893ee4495f2e190365f012dd`。来源压缩包为17525字节，SHA-256为 `333aaeb44b47b6b472b94a4e95c2dd81a0584bc3ad7274a698ba950331d847a9`。

对应独立核心为 `observed-zibai-resource-context.ts` 与 `observed-zibai-resource.ts`，正常编辑器为 `calculator-character-resource-controls.ts`。核心以共享AST累计、封顶、消费、重置冷却并延长到期时间；一次消费同时授权现有灵驹普通／月结晶两个分量。中央入口接线另由根代理完成，本模块未运行测试或构建。固定社区原文规则不等于已经验证实际游戏的全部执行细节。
