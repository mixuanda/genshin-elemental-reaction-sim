# 卡齐娜 C0 实际冲天转转寿命

倍率取自固定 [Optimizer 180a0a1 证据清单](../../src/character-mappings/optimizer-kachina-source-manifest.json)：搭乘与独立震荡各有完整 1–15 级 DEF 系数；A4 在解锁时额外增加一次 20% DEF 基伤。生成器仍按固定原文字节与目录值逐级核对。

[KQM Theorycrafting Library 的卡齐娜页](https://library.keqingmains.com/characters/geo/kachina) 于 2026-09-28 核对了动作关系：施放 E 获得 60 夜魂点，可立即搭乘或独立放置；独立实体间歇震荡，骑乘时普通攻击触发震荡；夜魂耗尽后实体消失。C0 Q 有一次 DEF 岩伤，并建立 12 秒领域，改变冲天转转的范围与骑乘移动；后续震荡仍归 E。C2 另有补 20 夜魂点的条件，故本完整寿命协议限定 C0。

固定来源没有足以确定首震荡帧、自动间隔、移动耗点或骑乘一次普通攻击实际扣点的可靠记录。gcsim 的 [Kachina PR #2697](https://github.com/genshinsim/gcsim/pull/2697) 在核对时仍未合并，审阅者明确指出帧数尚需重新计数。因此本模块不生成自动日程。用户按帧输入每次形态切换、震荡、命中／落空、动作后夜魂余额，以及余额为零后的消失；再确认记录覆盖完整实体寿命。固定倍率分支另要求明确全程没有 A1 夜魂迸发岩伤加成。只有这些事实完整时才显示该次 E 自身伤害总量。单次已发生震荡可独立计算，无需未来记录。

下落分支新增「一次途中碰撞＋低／高空着地」两击动作；已有零碰撞着地及独立碰撞入口仍保留。C0 Q 的直接伤害标为该 Q 自身完整伤害动作，领域效果按文字说明，不把 E 的后续震荡重复归 Q。

编辑界面的 JSON 格式占位数值仅用于展示字段形状，不是游戏观测。来源文字与计算核查支持条件化结果，不等同于游戏实测认证或完整队伍轮转。
