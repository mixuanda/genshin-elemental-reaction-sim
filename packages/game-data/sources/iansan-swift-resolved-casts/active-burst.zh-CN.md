# 雷霆飞缒：C0 实际 Q 增攻补充

此补充扩展既有 `iansan-swift-resolved-c0`，不修改原始压缩包、manifest、普攻倍率向量或原有天赋索引裁决。原包关于“Q 生效不在支持范围”的说明属于旧边界，本补充仅解除下述已明确实际条件的阻塞；不增加 Q 自身直接伤害、夜魂轮转或高命座支持。

固定 Optimizer `180a0a1015cb725c7570cd828eb086749960df98` 的 `Iansan/index.tsx:102–121,190–197` 将增攻授予当前场上角色，包括伊安珊本人，使用增攻前 `premod.atk`。固定 gcsim `a7dc4bf4f5e18390035ca0333fb6eb1d5fac32bd` 的 `burst.go:89–105,138–157` 同样包括本人，限定实际前台，Q modifier 为 Extra；其 `SelectStat(true,BaseATK,ATKP,ATK)` 排除所有 Extra，避免把 Q 自身或其他二次转换重新用于 Q。

实际一次 Q 刷新产生的固定攻击力为：

`min(该次刷新排除Extra后的攻击力 × (夜魂值≥42 ? 0.27 : 夜魂值×0.005), 独立有效Q等级上限)`。

Q1–Q15 上限依次为 `330,370,410,450,490,530,570,610,650,690,730,770,810,850,890`，来自原包 `skillParam.json.burst[3]`，与 gcsim 保留 DM 向量一致。补充 JSON 保存完整三组15级向量、原文件 SHA-256/计算所得 Git blob SHA-1 和固定路径。额外读取的固定 `cons.go` 仅保存来源身份和结论，不复制受 GPL 许可的 Go 原文，也不宣称已经独立核对其完整 Git 树。

gcsim 每18个角色任务帧重新取值；本功能读取该击实际使用的最近一次刷新依据，不用命中时的当前点数、当前最终攻击力或当前装备补造历史。普通 A1 可进入该次刷新依据，但它在该次刷新与本击取样时的状态可不同；本次 Swift 命中之后才授予的 A1 不增幅自身。当前有效 A1 的修正与 Q 固定增攻分别减去面板已含份额，再合并到一个来源攻击调整式中，各算一次。

完整合法、无卡肉/打断/替换的本次动作在25帧取样，最早31帧换人；24帧可衔接 Q 仍保持本人前台。因此完整日程可自动证明前台，不要求重复确认。明确本人后台与此完整路径冲突，保持阻塞。独立已发生命中或不完整日程不继承这项证明，仍须填写实际前台状态；独立已发生的后台命中不获得自身 Q 增攻。

兼容字段 `burstInactiveAtSnapshot` 保持 `true=未生效`、`false=生效`、缺省未知。旧 Q 未生效输入不新增刷新依据，原 A1 公式和转换身份保持可用。新字段均在 `gameContext.iansanSwiftResolvedCast`：

| 字段 | 含义 |
| --- | --- |
| `burstTalentLevel` | 独立有效 Q 等级1–15；不借普攻等级，不重复加命座等级 |
| `sharedState` / `hitStates` 中 `ownerOnFieldAtSnapshot` | 实际前台状态；完整合法日程可证明 |
| `burstUpdateNonExtraAttack` | 该次实际 Q 刷新采用、排除所有 Extra 的攻击力 |
| `burstUpdateNightsoulPoints` | 同次刷新采用的夜魂值0–54，允许小数及明确0 |
| `includedBurstAttack` | 输入攻击力已含的自身 Q 固定攻击份额；明确未含为0 |
| `snapshotIncludesActualBurst` | 实际历史最终面板已包含当时真实 Q；冻结后不再加算 |

实际 Q 刷新依据缺失时仍阻塞，历史文件不会自动获得这些证据。接受的 Q 历史快照及最终面板转换绑定事件、状态、普通攻击等级和独立 Q 等级；变更后拒绝复用旧快照。重新应用配装/导入会清除旧刷新依据；新装备可证明未含增攻为0，导入最终面板的已含份额仍未知。外来攻击调整公式保留原文并因槽冲突拒绝，不能被本角色公式覆盖。
