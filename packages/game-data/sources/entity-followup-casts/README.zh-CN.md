## 可编辑观察键

- 通用：`targetContacts`按编译候选id填写布尔接触；`snapshots`按`sample:<ownerId>:<frame>`保存实际完整面板。未声明共同面板稳定时不能借用当前面板；尼可每个造影无论是否稳定都必须提供其归属者快照。
- 雅珂达：吸收键`robot-1:absorb:6`起，未吸收时按`trunc(interval/3)`递推；每次攻击选敌键`robot-1:tick-1`；接触键`robot-1:tick-1:target-1`。每台机器人和每个选中目标独立编号。治疗键`heal:12`等。缺失检查只显示当前待补项，不把它当失败吸收。
- 尼可：`enemyHitEvents`填写全部实际事件并确认同帧顺序；接触键`projection-1`等。初击接触键为`initial`。
- 奥黛塔：E为`initial`，Q为`slash-1`至`slash-3`、`final`，倒影为`dance-1`起。
- `sharedState`与`hitStates`保留实际独立ATK样本、魔导附加基伤已含份额和雅珂达A4精通已含份额。外部历史快照不会因更换施放者当前装备而偷偷重算。
