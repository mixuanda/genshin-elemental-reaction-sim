# 奇偶固定原始技能补充

这不是“只在 UGC 中使用的外观身份”。HoYoverse 技术总监于 [2025-10-10 的官方 PlayStation 公告](https://blog.playstation.com/2025/10/10/genshin-impact-version-luna-ii-new-ugc-system-miliastra-wonderland-launches-oct-22/)明确说明，自定义奇偶也可用于提瓦特。固定原始表另有正式角色 `10000117`、`10000118`、各自八个技能配置、共同 LittleIdol 技能、天赋参数和执行结构。男女不是旅行者的别名；其动画/战斗配置身份各不相同。

本批依据公开可取得的 [Dimbreath/AnimeGameData2 固定版本 b061b403](https://gitlab.com/Dimbreath/AnimeGameData2/-/tree/b061b403c8afc7bca633cf4f201edc4a3baa75fe)。实际数据提交是 `9587d1afbd9ab0419cdd00dc05ecd114b9e3fe99`，标注 `CNRELWin7.1.0_R48145775_S48131320_D48145775`；HEAD 后续仅修改 README。每份原始文件的 Git blob 和 SHA-256 均与固定 GitLab 文件 API 的元数据一致，原文完整保留在 `source.json.gz`。这仍是社区分发的客户端数据，不是官方公开源代码或独立游戏实测。

原 catalog 没有奇偶天赋记录，因此本模块提供独立 `manekinTalentSupplement`。根解析器仅在原记录缺失、角色身份和天赋集精确匹配时使用，不覆盖 catalog 原件、发布状态或隔离预览。补充值标记 `single-source-extracted`，不能因两个性别共享参数就宣称独立交叉核验。

## 已落地字段

- 每个性别：N1、N2、N3（两击）、N4、重击（两剑）、无路径碰撞的低空/高空下落，共七个条件完整动作、九个命中模板。
- 每个性别：七种实际元素配置下的 E 单次直伤，各一个命中。无元素默认配置没有 E，不提供无元素 E。
- 合计 28 个条件完整输入、32 个命中模板。18 条原始十五级参数向量、270 个值另保留 E 持续时间、Q 区域进入伤害等明确字段；没有把时间、消耗字段当伤害。
- `AvatarSkillExcelConfigData` 将技能绑定到 proud groups 11731/11732/11739；`c43eab63.json` 的 LittleIdol_SkillUpgrade 将参数 `%1` 等绑定到具体伤害变量。`DamageHandler` / E / 下落执行结构再确认各变量的攻击用途。普通第三段 ×2 和重击两剑由原始说明与参数标签明确，未借旅行者次数。

正常控件要求真实本击状态为明确值；单击不索取未来完整日程。基础物理分支要求 E 元素转化与 Q 区域不生效、无外部附魔。E 分支要求实际所选元素配置、Q 区域不生效。完整输入另要求本输入已完整观察、无未计入自身追加伤害；无碰撞完整下落明确确认零碰撞。未知不默认成立。

## 保留的真实缺口

Q 初始与目标进入系数、8 秒区域、每 0.5 秒至多进入触发一次、离场结束，以及 A1 离场 200% ATK 尾爆均有来源；尚须目标进入/离场观察协议，不能只列一次 Q 就称完整。E 的 4 秒不可覆盖元素转化、离场终止、2 次使用次数和 10 秒冷却已归档，未伪装为自动团队状态。A4 后台低于 30% 能量时每秒恢复 2 点与装扮切换被动也只归档。

原表存在十五级数值，不证明每一级在当前规则下可取得；正常入口必须确认实际有效等级，未自动增加命座或突破等级。动画、命中停滞、取消、粒子、附着与 ICD 仍未由本补充证明。男女共同倍率不等于共同帧表。
