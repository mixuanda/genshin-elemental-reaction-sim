# 洛恩：实际观察的欢悦／争胜账本

本包支持 C0 的真实资源事件按 `frame`、同帧 `order` 重放，并将一次实际消费绑定到已有独立 E 段或 Q 六斩。输入是已经观察到的事件，不生成动画、队友伤害或整场轮转；状态保持 `source-assumed`。

## 固定来源与保留冲突

Optimizer 固定提交为 `180a0a1015cb725c7570cd828eb086749960df98`。五份原文为 LICENSE、Lohen sheet、skillParam、英文角色文本和 tooltip 文本，均与未截断 Git 树的 blob 身份吻合。KQM 固定提交 `0239a3b101f23b9b82a6dec6070151d1cbbdc5cf` 的 `src/data/characters/Lohen.json` 是第六份原文，blob 为 `c03cbc60733c37518cfa67e94cbdf6c1b21f0339`，与该固定提交的 contents API 对应。

压缩包 `source.json.gz` 的 SHA-256 为 `0d1b3fbee2fb3575fb7fa3cb20184b4d526647fdf7bdcc9aa68d8559fcee51a2`。原文身份、选中树记录及引用在相邻 manifest、definitions 和 archive 中保存。六份文件来自两个仓库，不把它们声明成全部属于同一个 Git 树。

Optimizer 的生成 tooltip 键 `11290003`、`11290004` 错把伤害参数替进资源说明，产生欢悦 `0.381298`、争胜阈值 `55.2868%`、获得量 `0.829302`。这三个错误字符串原样保留在归档与 `retainedConflict`，不用于计算。数字采用同提交 sheet 对 `skillParam` 的明确字段绑定：`skill[12/13]=17`、`skill[14]=10`、`skill[15]=20`；固定 KQM 原文独立给出17、白字1000%和20。A1 的白字3000%与额外60也由两份固定原文对应。KQM 尚无该角色 findings，故这里不是帧实测认证。

## 已实现的共享规则

- 奇谋基础13秒；以本应用每秒60帧单位表示780帧，要求观察区间无卡肉。自身普攻／重击实际命中给予17欢悦，上限100，途径共享0.1秒冷却。
- 其他附近队员的实际单次伤害低于洛恩当时白字攻击的10倍，给予1争胜；达到阈值给予20。A1有效且达到白字30倍时另加60。每个其他队员分别有0.1秒冷却；争胜上限100。
- 欢悦100允许实际施放镂骨彻心，每姿态最多三次。施放先占次数；命中敌人后才消费全部欢悦和争胜。明确落空不消费，仍计施放次数。第三次施放后不能新增欢悦，不擅自使姿态提前结束。
- Q在施放时消费全部争胜；六斩绑定同一次消费，不重复扣除。若奇谋有效，Q延长1.65秒，即99帧。Q不消费欢悦。
- 实际离场或奇谋结束清空双资源。完整姿态查询需要显式退出事件。恰在持续期或获点冷却边界的事件需要实际状态布尔输入，不猜包含端点或回调先后。

`resolveObservedCharacterResources(context,{throughEventId})` 仅执行截至绑定消费的事件前缀；未来逻辑事件不影响已发生单击。整个输入仍需满足结构 schema。`requireCompleteStance:true` 才要求完整姿态退出。

## 接线与独立算例

游戏上下文为 `gameContext.observedCharacterResources`，schema 导出于 `observed-character-resource-context.ts`。`hitBindings` 用完整命中 ID 映射消费事件；缺逐击绑定时采用 `consumptionEventId`。`prepareObservedCharacterResourceDocument` 在已有来源公式生成后调用，用实际消费整数替换 `lohenWillConsumed`，不再限于旧 sheet UI 的20倍数选项。已有依赖仍保留；缺初态、实际白字、资格或绑定会阻塞本击。最终面板转换调用对应 finalize/reset；trace 使用 `observedCharacterResourceTrace(document,hit)`。

一个无需动画假定的观察算例：起点帧0、有效奇谋、到期780、双资源0、Etch已用0、获得冷却明确就绪。自身六次命中分别在1、8、15、22、29、36帧，使欢悦变为17、34、51、68、85、100。其他队员A在2帧伤害24000、洛恩当时白字800，突破阶段6，获得20+60=80争胜；队员B在3帧伤害1000，获得1，合计81。37帧实际施放Etch，38帧实际命中，消费欢悦100与争胜81。

该独立 E 伤害段 Lv1 倍率0.6、每点争胜额外0.004；实际ATK2000时，基础伤害 `2000×0.6×(1+81×0.004)=1588.8`。等90级敌我、无减防／无穿防、抗性0.1、CR0.5/CD1、其他加成为0时，期望伤害 `1588.8×0.5×0.9×1.5=1072.44`。这是现有 Etch **一个伤害段**的算例，不把原四段动作的单个模板冒充全技能完成。

## 尚未完成

未自动生成洛恩姿态普攻／重击／下落、Etch全四段动画、A4攻击增益与意气洋洋技能等级事件、魔导队伍效果、命座或真实团队执行。资源账本不能替代实际面板、有效天赋等级或队友伤害模型。Kachina 的固定文字可证明入场60点与耗尽退出，但本批未取得按动作扣点量、持续耗率和首脉冲帧的足够来源，不能据此生成她的完整姿态日程。

本模块与正常事件行编辑器仅完成静态核对；测试、构建和数据命令统一由根代理安排，本目录未自行运行。
