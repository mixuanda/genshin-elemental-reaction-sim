# 普通与直接特殊反应的完整来源施放

本包包含菈乌玛长按E、菲林斯普通Q、奥黛塔终奏及旧倒影升级尾段。证据维持 `source-provisional`，不是当前游戏机制实测或自动队伍支持。

`definitions.json` 是3个动作、15个伤害角色的唯一倍率入口。其中6个普通角色注册为动作入口，其余9个直接月曜／星烁角色由计算器生成真正的 `special` 命中，不以普通增伤、防御公式近似。17个独立15级参数向量共255值与活动目录快照及固定 genshin-db 原始 stats 精确相等，容差0；其中一个向量是减抗参数。

来源固定为 gcsim b4ae769（菈乌玛、菲林斯）及 a7dc4bf（奥黛塔）、genshin-db 49a6544。39份原文保存在 `source.json.gz`；逐文件 SHA-256、Git blob SHA-1、固定版本和归档哈希见 manifest。b4原文与固定完整tree匹配；a7已有实体归档覆盖的奥黛塔原文另与其SHA-256匹配，未把提取身份升级为新的独立远程验证。
