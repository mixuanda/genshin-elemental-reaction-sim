预设 JSON

直接编辑角色、行动、Buff 与命中段

          

          

            
核心字段

            

              
characters
角色面板、等级、能量上限与初始能量。

              
rotation
一个循环内的行动。系统按 cycleLength 自动重复至 duration。

              
hits
每段伤害的偏移、倍率、附加基础伤害、元素、反应和快照方式。

              
buffs
支持 atkFlat、atkPct、dmgBonus、critRate、critDmg、em、defIgnore、reactionBonus 和 energyRecharge。

              
debuffs
支持分元素减抗与防御降低。

              
energyGains
只描述不受充能效率影响的固定回能；不足能量的行动会被跳过并记录。

              
particles
描述微粒/晶球的元素、离散数量范围、生成帧与飞行帧；核心在到达帧按前后台、同/异色和充能效率向全队分配。

              
timeline
启用 legal-frame-v1 后，以 60 FPS 整数帧描述行动定义和命令序列；支持切人、取消帧、动画结束、冷却、充能次数，以及 strict / wait 合法性模式。

              
reactionEngine
启用 aura-v1 后，由模拟核心根据每段 application 的元素量、icdTag、icdGroup 和敌方 Aura 自动判定融化/蒸发；正式预设禁止手工 reaction 标签。

            

            
旧配置继续使用绝对秒兼容模式；legal-frame-v1 的行动和命中使用整数帧。aura-v1 目前只实现火/冰/水普通 Aura、可扩展元素量、默认三击/2.5秒 ICD、No ICD、融化与蒸发。粒子规则已有机制闭环，但真实角色产球、动作帧和角色/武器数据库仍未完成；元素共存、冻结、感电等转化反应也未实现。
