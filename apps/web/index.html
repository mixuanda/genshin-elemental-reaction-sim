预设 JSON

直接编辑角色、行动、Buff 与命中段

          

          

            
核心字段

            

              
characters
角色面板、等级、能量上限与初始能量。

              
actorPoses
可选的场景静态角色坐标与二维朝向；geometry.coordinateSpace 为 actor-local 时，核心按施放者姿态旋转并平移为世界坐标。当前不会自动移动或转向。

              
rotation
一个循环内的行动。系统按 cycleLength 自动重复至 duration。

              
enemy.targets
注册具名目标并可分别覆盖等级、抗性、减防、初始附着、静态二维坐标和碰撞半径；省略时保留兼容目标 enemy-0。每个目标的 Aura 与附着 ICD 状态独立。

              
enemy.targetMotions
按目标声明有序、不重叠的 60 FPS 线性移动分段；分段间保持上一位置，核心按每次命中帧插值并返回解析后的移动时间线。

              
enemy.targetPhases
按目标和 60 FPS 声明有序、不重叠的半开阶段；开始帧生效、结束帧恢复。不同目标的阶段可以同时存在。

              
hits
每段伤害的偏移、倍率、附加基础伤害、元素、反应和快照方式；可用 targeting 选择已注册目标、显式 landed / miss，或覆盖阶段策略；也可用 geometry.circle、可旋转 geometry.rectangle、由起终点和扫掠半径定义的 geometry.capsule，或由圆心、半径、方向和夹角定义的填充 geometry.sector，按命中帧位置求交全部目标。几何默认使用世界坐标，也可声明 coordinateSpace: actor-local。

              
buffs
支持 atkFlat、atkPct、dmgBonus、critRate、critDmg、em、defIgnore、reactionBonus 和 energyRecharge。

              
debuffs
支持分元素减抗与防御降低。

              
energyGains
描述不受充能效率影响的固定回能，可声明按来源角色和键共享的内部冷却；每次触发或阻止都由核心记录。

              
particles
描述微粒/晶球的元素、离散数量范围、生成帧与飞行帧；核心在到达帧按前后台、同/异色和充能效率向全队分配。

              
timeline
启用 legal-frame-v1 后，以 60 FPS 整数帧描述行动定义和命令序列；支持切人、分后续行动取消帧、动画结束、冷却、充能次数、能量失败回滚，以及 strict / wait 合法性模式。

              
reactionEngine
aura-v1 根据每段 application 的元素量、icdTag、icdGroup 和敌方 Aura 自动判定融化/蒸发；aura-v2 另加入雷 Aura、超载/超导独立范围伤害、水雷共存/感电周期流，以及带逐帧加速衰减和冻结抗性的冻元素耐久。冻元素可被火正向融化或雷冻结底超导消耗，并阻止火打水反向蒸发、冰打雷普通超导和新感电等错误分支。正式预设禁止手工 reaction 标签。

            

            
旧配置继续使用绝对秒兼容模式；legal-frame-v1 的行动和命中使用整数帧。具名多目标、逐目标 Aura/ICD/冻结抗性、超载/超导独立伤害、超导物抗状态、水雷共存/感电周期流、冻元素耐久、显式 AoE 扇出、二维圆形/旋转矩形/胶囊/填充扇形求交、静态施放者局部坐标变换、声明式目标线性移动、一次产球聚合、landed / miss、三层策略和阶段窗口已有机制闭环；碎冰、扩散、结晶、草反应等仍未实现，冻结也不会自动定身或停止声明式移动。几何仍不含高度、角色移动、自动转向、AI 移动、索敌或障碍物，也没有完整角色机制数据库。
